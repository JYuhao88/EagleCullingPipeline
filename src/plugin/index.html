服务检查与升级

更新继续使用同一个插件目录，不需要卸载、重建或清空设置。

  1. 若旧窗口正在执行任务，先暂停并等当前请求结束。进度不动不代表请求已停止，不要强制结束进程。
  2. 关闭旧插件执行窗口；确认没有在途操作后，再退出旧本地服务。重载插件、重启 Eagle 都不等于升级本地服务。
  3. 在项目目录运行 powershell -NoProfile -ExecutionPolicy Bypass -File scripts/start-service.ps1。启动脚本遇到旧版或端口被占用会拒绝重复启动，不会杀进程。
  4. 点击“重新检查服务”，确认插件与服务版本一致；重载同一个插件入口后，在任务页继续剩余项目。

如果只是隐藏本插件角标，直接切换显示开关，无需服务升级或恢复任务。旧 Eagle 网格角标是此前写入的缩略图内容，不会随着重载自动消失。
