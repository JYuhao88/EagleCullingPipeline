# 摄影书籍提炼流水线与《摄影美学六讲》试点

日期：2026-10-10。工作分支：`w3-books`。本轮由当前助手阅读并归纳，不调用外部模型，不上传书籍，不下载补充书目。

## 1. 新书进入流水线

从本 worktree 根目录运行（输入文件只读）：

```sh
python ml/references/books/extract_book.py '/绝对路径/新书.epub' --slug my-photo-book
python ml/references/books/extract_book.py '/绝对路径/新书.pdf' --slug my-photo-book-pdf
```

默认输出 `/tmp/books/<slug>/toc.json` 与 `chapters/01.txt` 等；macOS 中 `/tmp` 解析为 `/private/tmp`。`toc.json` 含书名、作者、格式以及每节的 `number/title/file`；EPUB 另存 archive `resource`，PDF 另存 `page`。输入不移动、不修改。slug 仅允许字母、数字、下划线和连字符。

EPUB 仅用 Python 标准库：读取 ZIP 内 container、OPF manifest/spine，按阅读顺序抽取 HTML 正文，去掉 head/script/style，解码实体；标题来自 EPUB2 NCX 或 EPUB3 nav，缺标题时取正文 heading。跳过空文本资源和 `linear=no`。章节粒度为 spine 文档，同一 HTML 内多个目录锚点不重复输出，也不细分。抽取器不访问链接或提取图片。

PDF 优先使用已有 `pypdf`，否则使用 `pdfplumber`。每页作为一节，正文保留 `[p.12]` 这样的物理页标记；并非印刷页码。如果两者都没有，脚本给出友好错误和以下安装命令。本轮没有安装依赖：

```sh
python -m pip install pypdf
# 或
python -m pip install pdfplumber
```

扫描 PDF 没有 OCR，空页仍保留页号；PDF 不自动按目录重建逻辑章节。加密 PDF 需要用户提供可读副本。不要把没有提取出的文字当成已经读过。

提炼步骤：

1. 核对书名、作者、目录与文本完整性，逐节阅读正文及图片说明。只将抽取全文留在 `/tmp/books/`；不要复制到仓库或上传服务。
2. 对照四个正式规则库和衣刀、小红书候选。已有内容优先写成出处、例外或反向提醒；不能用书籍观点补造测量阈值或权重。
3. 将记录追加到 `src/rules/candidates/book-evidence.json` 的 `books/evidence`；每项必须有真实 `ruleId`、`bookSlug`、`kind`、≤40 字转述及可复核 locator。
4. 仅把当前照片可见、现有规则未覆盖的观点加入 `book-candidates.json` 的 `rules`。包含规则库字段、适用 `library/genre`、`status:proposed`、`severity:hint`、`source:book:<slug>`、最多 4 条短证据与定位。未确定适用性时宁可不建候选。
5. 将理论、拍摄过程建议、依赖作者内心或历史身份的信息留在报告。单列连拍与多张比较线索，说明是书中直接论述还是本轮归纳。
6. 用下文测试校验契约，进入 `/rules/review` 人工审核；书籍证据展示不等于正式规则、测量或排序已经改变。下次加书沿用两个 JSON 文件，不覆盖已有书目。

## 3. 主要结论与规则建议

- **视觉比重胜过固定比例**：亮暗、色彩面积及虚实共同影响平衡。已映射到 `G-FRAMING-BALANCE`、`L-HORIZON-PLACEMENT`，没有新增构图公式。
- **低反差与灰调不是天然缺陷**：柔光可以形成整体，灰色可衬托鲜艳主体。补充 `P-YD-TONAL-GRAY`、`P-YD-LIGHT-FLAT` 例外；依然检查关键内容是否可辨。
- **留白与小人物可以成立**：环境人像、象征性人物不宜机械套头顶尺度或主体面积。记录 `P-CROP-HEADROOM` counterpoint、`P-SUBJECT-PLACEMENT` exception；后续审核宜明确近景人像与环境人像的适用性。
- **焦点服从主要内容**：梳妆时手部动作可为主，灯光与窗框也可成为中心。补充人眼焦点、眼部裁切及整图模糊规则的适用例外；不是免除所有技术检查。
- **明暗与色彩服务主次**：背景艳色可能抢戏，局部暖色可成为视觉中心。已有小红书与衣刀候选覆盖，补出处，不重复建规则。
- **画面完整不等于物体全貌**：取舍、遮挡、倒影可保留关系与氛围。没有把这一点写成关节裁切普遍豁免，也没有用书中的局部景物案例证明人像坏切无害。

唯一新候选是「树木形态支持画面表达」：树作为主角时，描述枝干曲折、疏密与轮廓变化。它补足既有观看路径、前景、光线规则没有直接描述的树形内容。只作为比较提示；规整树形、人工修剪和类型学同样可成立，不设越弯越好的分数。

本轮没有改正式规则 `sources` 或替换 `todo:book`。建议人工审核后逐项用真实书籍引用替换已支持部分；人像手指、膝腕裁切、重心等未得到本书足够支持，不能把本书挂成这些规则的来源。

过曝和倾斜的证据边界：本书明确提醒保住亮部，并没有支持「大面积不可恢复高光总能成立」；本轮不添加这种例外。翻转倒影说明方向处理可以有意，**不能推广为任意荷兰角都成功**。低调例外来自剪影、灯光中心与隐藏杂枝；关键动作和轮廓仍应能读懂。

## 4. 连拍／多张中选哪一张

书中没有系统的 contact sheet 或连拍编辑流程。以下是从案例归纳出的组内比较问题，单张可观察相关状态，但优劣仍须与邻帧及摄影师意图比较。

| 可见比较线索 | 书中定位 | 对应规则与边界 |
|---|---|---|
| 一脚在门内、一脚在门外，空间关系清楚 | 第六讲／禅意摄影的美 | `S-MOMENT-ACTION`；过渡动作也可成立，不强求动作峰值 |
| 举手机时人物、窗与倒影形成呼应 | 第四讲／构图，到底是什么 | `S-PERSON-GEOMETRY`；比较关系何时成立 |
| 船的运动、水花或水纹增加可见动态 | 第一讲／知识之外的无言之美；第二讲／50mm焦距，进退自如 | 作为瞬间线索，不建立速度评分 |
| 鱼游到适合位置，画面视觉比重变化 | 第六讲／看见水里的风花雪月 | 比较对象与倒影位置，不凭锐度选赢家 |
| 自然神态、手部工作动作与环境相呼应 | 第二讲／35mm定焦镜头，是一把平衡的尺子；50mm焦距，进退自如 | `P-FACE-EXPRESSION`；不把笑或看镜头设为必选 |
| 倒影与结构完整，关键关系不被意外截断 | 第二讲／35mm定焦镜头，是一把平衡的尺子 | 比较关系完整性，不要求所有物体完整入画 |
| 不同色彩面积的多次取景 | 第四讲／构图法则之色彩平衡 | 本书直接建议多拍几种比例后比较；不必属于连续连拍 |
| 同场景四季的时间变化 | 第六讲／营造时光流动的感觉 | `S-UNIQUE-COVERAGE` 的用途补充；不是普通连拍，不能因相似而只留一张 |

情绪判断需要克制：可描述步态、动作、姿势、明暗与色彩效果，不能仅凭衣着与剪影确认师徒关系、心理状态或历史人物。书中部分联想被记录为 `S-NARRATIVE-EVIDENCE` 的 counterpoint，不能转成身份事实。

## 5. 审核接口与导出

`GET /rules/data` 保留原字段，新增 `bookCandidates`（完整候选文件）、`bookEvidence`（完整映射文件）。待审核候选仍在 `rules` 中；相应规则详情的 `bookEvidence` 附书目元数据和 locator。landscape/street/general/小红书中有书籍证据的规则加入 `referenceRules`，保持只读；既有衣刀、人像审核语义保留。

审核页可按「书籍／其他」筛选来源；带书籍补充的已有规则也属于书籍范围。详情的「书籍出处/例外」只展示转述、类别、书名、作者和定位，不请求图片或书籍文件。

书籍候选可沿用通过、修改、删除操作。为兼容人像导出契约，非人像候选不能合并入人像种子；`POST /rules/export` 的旧 `draft/path` 保持人像草案，另以 `bookDrafts[library]` 返回已批准的其他库候选。页面将其下载为 `<library>.books.draft.json`；服务器只保存原有的人像 review draft，不修改正式库。书籍证据有独立去重键，不计入视频频次。本轮没有对真实规则提交审核决定或执行导出写入。

## 7. 局限与验证

本书主要是中国风美学与拍摄经验，不是通用选片手册。文化、颜色与情绪的对应是作者的表达立场，不能当普适心理学真值。关于显示器校准、器材轻便、审美训练、文学体验和作者心境的建议不进入单张候选；浏览器色彩管理也不能仅凭书中的历史简化描述下结论。

全文未做 OCR 或图片分析，插图本身没有进入规则正反例；提炼者也是验证者，尚需摄影师审核。书籍出处不能证明规则权重、机器可判断性或实际选片效果；正式库、ranking、signals 本轮均未变更。

### 8.3 产物、Top 观点与交叉证据

本轮追加 **52 条映射**：28 source、20 exception、4 counterpoint，覆盖 **32 个不同规则 ID**。另追加 **1 条 proposed/hint 人像候选** `P-BOOK-EXPRESSION-VARIETY`，用儿童肖像书的表情序列观点支持多帧互补；不设笑容、睁眼或相似度阈值。累计书籍数据为 13 本、90 条映射、2 条候选。

- **比较必要内容，而非整图锐度**：The Camera 区分边缘锐利感与细节分辨力，并提醒交付尺寸与观看距离；选择性对焦服务主次。与衣刀背景虚化、细节候选及小红书主体层次观点一致，补充 `G-PROXY-BLUR` 的反向提醒。没有认证代理图清晰度阈值。
- **明暗由具体内容决定**：The Negative 要保住所需暗部，也区分有意明暗变化和曝光失误；小面积镜面高光可以没有细节。Capturing Light 的点光源与剪影进一步支持现有街拍例外。与衣刀「所需信息不可辨才有问题」一致；不能把胶片负片的曝光宽容度结论套到数字 RAW，也不支持必要人脸细节的严重溢出。
- **柔光不必扁平，硬光也不必淘汰**：Capturing Light 的灰光呈现同类颜色差别，窗光同时有塑形与软阴影。与六讲试点、衣刀 `P-YD-LIGHT-FLAT` 的条件句和小红书 `P-LIGHT-SHAPE` 一致；「阴天一定差」没有依据。
- **自然姿态要结合用途**：传统商拍书支持重心区分、手指避免粘连、腿部轮廓分离；另一批案例明确允许方正肩线、正式静态合影、轻握拳、困倦或睡眠肖像。与衣刀「僵硬且不符合自然状态」一致，但与正式库 `P-POSE-WEIGHT` 对正面平肩的普遍负面措辞、`P-HAND-NATURAL` 对握拳的概括存在冲突，应补用途条件。
- **平衡不是面积均分**：构图书用较小但反差更强的物体平衡较大物体；商业肖像也有有效居中案例。与衣刀／小红书 `G-FRAMING-BALANCE` 的画面关系评价一致。Master Guide 偏好三分线的传统段落作为 counterpoint 保留，与现代库允许居中或可变天空比例的范围差异并列，不改成几何硬门槛。
- **表情、轮廓和时序比一张通吃更可靠**：Manning 强调视线、神态和手势；Freeman 用联系表讨论单张首选与完整事件发展；Hurter 明确婴儿不同表情可构成序列。与现有街拍独特覆盖、衣刀动作瞬间及互动观点一致，人像表情序列则补为新候选。

建议人工审核后修改的措辞：`P-POSE-WEIGHT` 增加正式、对称、有意稳定姿态的例外；`P-HAND-NATURAL` 区分无意僵硬与有意握拳／持物；`P-FACE-EYES` 明确睡眠婴儿场景；`P-CROP-HEADROOM` 在特写与环境肖像中先核验表达用途；曝光规则区分有内容用途的点光源／镜面高光与关键人物不可恢复细节；`G-PROXY-BLUR` 提醒交付尺度与局部焦点。上述均为待审建议，**正式库、ranking、signals 没有修改**，也没有增加可测权重或参数阈值。

没有收录作者把某种姿态解释成具体性格、性别角色或身材价值的说法。视线只记录画内方向与交流对象，不凭相互背向断言关系不和。客户用途、拍摄者内心和真实性认证不能单凭照片决定，留在报告；没有把拍摄流程、设备推荐或后期操作误作成片规则。

**每本 Top 观点与连拍／合影落点**：

- **Heron**：神态不等于笑容，认真、沉思、哭泣或说话时的独特表情也可有价值（30／2、9、12）。连拍直接案例是拍手婴儿：喜悦神态未被手遮挡，比拇指紧贴鼻部的一帧更好（76／9–10）；跨栏组照逐人比较可见性、腾空与排布，既避免散得太开，也避免挤到遮挡（76／7）。泡泡组照按表情与泡泡的目标选择，可改善取景不一定压过神态（80／13）；技术合格但普通重复的帧会稀释佳作（80／20）。儿童合影难在各年龄孩子同时呈现好神态（96／2），本轮由此归纳逐人比较问题，不声称作者给了自动算法。作者另设纪念快照类别（80／22），允许技术不佳但有事件价值的照片留存；没有“只保留最开心的一帧”的依据。
- **Murphy**：有好构图和用光仍须检查眨眼、尴尬神态及人物出框（91／10、13）。正式合影逐人复核视线：不同人盯着不同相机，可能让全组状态分散（80／70）；用阶梯排布压缩长队、照顾所有人入框（80／65），并逐人看受光与清晰度，不能只让中间人物到位（80／5、63）。摆姿间隙的自然互动也有选片价值（80／41）。连续驱动不是可靠峰值保证（61／8），真正选择仍看成片；相册覆盖按事件阶段考虑（104／5），具体交付数量和比例是商业流程建议，不进入规则。
- **Sammon**：合影各人头部应分离，前后错落时不能只让新郎清楚、同伴模糊（125／3–4）。退场连拍直接建议比较笑容、位置和用光，飘落彩带／花瓣的位置不可预测（208／4）；动作峰值是线索（143／3），不是全组所有人的单一总分。交付应有全景、远摄、近景、正式与抓拍的互补（119／3–4），画心序列靠开始至完成的进程成立（137／4）；不进相册的序列帧仍可能被亲友用于分享（137／2）。这支持去掉无变化的重复，却保留动作发展或不同信息，不把相似图强制压成一张。
- **McNally**：光、色与手势可共同承载合影；三人互相亲吻的反应案例说明摆拍也可以产生有效互动（38／62–69）。批改试卷的一组神态，单帧力量有限、序列整体更有效（41／58）；舞者脚部细节补足大场面照片的内容（37／27–32）。这些是直接叙事案例，不是最大笑容或连拍赢家判据。三人棒球合影把体量较大的人放中间只是具体排布案例（37／33），不推广为按身高排序规则；家庭旅行的安静小瞬间也值得记录（79／12–16），不凭作者对女儿性格的解读给照片打分。
