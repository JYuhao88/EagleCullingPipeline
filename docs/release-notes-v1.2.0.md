# v1.2.0 发布说明

v1.2.0 重做插件新手体验，加入插件内自动更新，并修复 Windows 上的卡死问题。
排序、规则和评分模型未改变；同平台合成基准三项指标不退化。

## 新增与改进

- 新主页：服务状态卡、三步引导、随状态变化的主按钮、「最近的分析」列表和折叠的高级设置；审阅页精简。
  新增只读分页接口 `GET /runs`。插件启动服务改为跨平台（Windows 不再依赖 `nice`）。
- 自动更新：插件定期检查公开仓库的正式版本 tag（`git ls-remote`，不依赖 GitHub REST API），
  有新版显示横幅；「自动更新」默认开启，仅在空闲且不在审阅时执行。更新整个克隆，
  lockfile 变化时 `npm ci --ignore-scripts`，候选服务健康后接管端口，失败自动恢复；支持回退到上一版。
  工作区有未提交改动、正在分析或目标不在 master 历史上时拒绝更新。首次安装需使用 git 克隆，见 `docs/auto-update.md`。
- Windows 稳定性：缓存原子替换遇到 EPERM/EBUSY 时退避重试；分析进行中显示忙碌状态，
  重开插件可恢复进行中的任务，断网自动重试，中断任务停止轮询；提交分析先返回再后台扫描并报告进度。
- Eagle 原生缩略图审计与迁移脚本（`npm run audit:native`）；相关脚本需通过环境变量提供资料库路径。
- 研究工具（默认关闭）：外部视觉模型作为老师的试点与扩大验证脚本及报告；Ray 远端冷算基准。
- 公开发布检查新增 Windows 本机路径识别。

## 已知限制

- 外部老师模型在真实组上首选一致率约 33%，倒序复问稳定率约 60%，不作为排序先验。
- Windows 8000 张首次分析按 500 张实测线性估算约 2.5 小时，未做全库实测。
- 跨平台关键点置信度在阈值附近仍有微小差异，质量门槛须同平台比较。v1.1.0 的其余限制仍然适用。
