# 使用场景与交互设计（v1.6）

本文从摄影师的使用习惯出发，定义插件的核心对象、每种状态下界面给什么、再次打开时如何接上上次的工作，以及无法接续时怎么办。界面实现以本文为准。

## 1. 摄影师怎么挑片

- 一次拍摄是一个工作单位：导入 Eagle 后通常放在一个文件夹里（按日期或主题），挑片也按这一批来做。
- 挑片经常被打断：先挑一部分，吃饭、睡觉、第二天再接着挑；大型拍摄（婚礼、活动）要分好几次才能挑完。
- 回来时最想要的是“回到我停下的地方”：同一批、同一组、同一张、同样的筛选。
- 同一批会变化：补导第二张卡、删掉明显废片、在 Eagle 里改了标签。
- 挑完要让结果在 Eagle 里可见（星级），之后在 Eagle 里继续修图或交付；不需要再做一步“写回”。
- 机器状态会变：服务被更新重启、电脑睡眠、Eagle 退出、插件窗口被关掉。这些都不能让已经做的选择丢失。

## 2. 核心对象：分析记录

用户心里的单位不是“一次运行”，而是“这一批照片的挑片工作”。内部称为**任务**；界面不让用户管理任务：
首页只给出此刻该做的一件事，以前的分析放在「设置 › 分析记录」，界面文字不出现“任务”。

- 任务 = 范围 + 最新一次分析 + 人工决定 + 写回状态。
- 范围有三种：一个文件夹、一组选中的照片、整个资源库。范围用稳定的键识别：`folder:<文件夹 ID>`、`selection:<照片 ID 摘要>`、`library`。
- 同一范围再次分析（补充新照片、更新分析、旧记录无法续跑后重做）生成同一任务的新版本：**之前的人工决定按照片自动带到新版本**，旧版本标记为“已被新版本取代”，默认不在列表中显示。
- 人工决定按拍摄单元保存（`unit:<主文件 ID>`），只要照片还在，换版本、换范围都能对上。

## 3. 任务的状态与动作

首页始终只有一个主按钮，取决于当前最该做的事。下表的“其他”列是分析记录每行的次要按钮。

| 状态 | 用户看到 | 主按钮 | 其他 |
|---|---|---|---|
| 分析中 | 进度、阶段、剩余时间；可以关窗口，完成后通知 | 无（进度卡就是主体） | 取消 |
| 已中断（服务重启、电脑睡眠、更新） | “上次分析在 65% 中断，已完成的部分会复用” | 继续分析 | 删除任务 |
| 已取消 | “已暂停在 40%” | 继续分析 | 删除任务 |
| 失败 | 用人话说明原因 | 重试 | 连续失败时显示诊断与日志位置 |
| 无法续跑（缺少续跑记录、旧版本格式） | “这条记录无法从中断处继续” | 按原范围重新分析（决定会带上） | 删除任务 |
| 原范围找不到（照片记录丢失、资源库不同） | “找不到原来的照片范围” | 在 Eagle 重新选择后分析（决定会自动带上） | 删除任务 |
| 待挑选 | “还剩 5 / 12 组” | 在 Eagle 中挑片 | 报告与清理… |
| 已挑完 | “全部决定，结果在 Eagle 星级里” | 在 Eagle 中挑片 | 报告与清理… |
| 范围新增照片（文件夹多了照片） | “文件夹新增 8 张” | 补充分析（只算新增，决定保留） | 先挑已有的 |

照片在 Eagle 中被删除：审阅时隐藏这些照片并提示数量；写回时跳过并在结果中列出。

## 4. 打开插件时显示什么

从 Eagle 插件菜单打开插件，先显示宽屏检查器：跟随 Eagle 选中的照片，窗口铺满屏幕。点「返回主界面」进入下面的首页，首页的「宽屏检查器」再回到宽屏。关闭宽屏窗口后，插件回到首页在后台运行（服务、更新、空闲预处理照常），下次打开仍是宽屏。

首页显示的那一刻，Eagle 里的选择代表用户此刻的意图。首页按以下顺序决定主卡片：

1. **服务未运行**：自动启动；失败时主按钮是“启动服务”，诊断折叠在下面。服务不可用时不显示需要服务的按钮。
2. **有分析正在进行**：进度卡。
3. **当前选择（文件夹或照片）已经属于某个任务**：
   - 完全覆盖：显示该任务的状态与对应主按钮（在 Eagle 中挑片 / 继续分析）。
   - 有新增照片：主按钮“补充分析 N 张新照片”，次要“先挑已分析的”。
   - 只是任务的一部分：主按钮“在任务中查看这 N 张”。
4. **当前选择是新的**：主按钮“分析这 N 张”，显示预计耗时（已分析过的照片会复用）。
5. **什么都没选**：提示在 Eagle 里选文件夹或照片；如果有没挑完或没分析完的，主卡片是“接着上次”。整库分析只作为次要按钮，显示张数与预计时长，点击后确认。

首页不列出以前的分析。「设置 › 分析记录」按“需要处理的”排序：分析中、待挑选、可继续分析，然后是已挑完。每行显示状态、进度和对应的按钮。只显示当前资源库的记录。

## 5. 审阅会话的连续性

- 每个决定立即保存在本机服务中，与窗口、插件、Eagle 是否关闭无关。
- 检查器随 Eagle 当前选中照片显示对应任务、分组和决定。主窗口的「在 Eagle 中挑片」选中任务第一张照片。
- 撤销记录只在当前会话内有效；跨会话可以直接改决定。
- 补充分析或重新分析后打开新版本：已挑过的照片保持原决定，新照片标为未挑，默认先看未挑完的组。

## 6. 挑片方式

主窗口负责范围选择、设置、开始分析和进度；报告导出、回收站清理和可选的 AI 标签写回在「设置 › 分析记录」。
分析完成后主按钮为「在 Eagle 中挑片」，选中任务的第一张照片后，由 Eagle 预览和右侧检查器接手。
照片查看、放大和浏览使用 Eagle；主窗口不提供照片预览网格、审阅页或专注挑片视图。

**右侧检查器**：在 Eagle 中选中照片后，检查器显示 AI 建议、人工决定、任务进度和分组信息。
组内比较表展示排名、评分和问题标记，列出当前照片相对本组最佳照片的差异；大缩略图便于识别组内照片，
点击后在 Eagle 中选中。检查器承担逐张决定、组间导航、分组修正和整批批量操作。
多选时可对选中照片统一决定；本组接受 AI 建议及整批批量处理均在检查器中完成。
旧版 Eagle 没有 `item.select` 时，需要在 Eagle 手动选择照片。
「细节与调节」放大主体局部，并提供曝光、对比度、高光、阴影、白色/黑色色阶、色温、色调和饱和度，
同时作用于局部图和对比的两张照片，便于在同一观感下比较。调节值按照片存在分析记录里，不改原图、星级和评分。
它调整的是显示用的 JPEG 或机内预览：已过曝的高光不会恢复，高光和阴影是全局曲线，不是 Lightroom 的局部自适应。
局部图用滚轮或双指以光标为中心缩放，拖动平移，双击在适应和 100%（原图一像素对一个屏幕像素）之间切换，右下角显示比例。
「对焦框」画出相机记录的对焦位置（实线为合焦区域），默认放大到那里；哈苏等不记录对焦点的相机会注明。
「合焦高亮」把当前看到的清晰边缘标红，所有相机都可用；它反映当前显示尺寸下的锐度，放大到 100% 附近判断最可靠。

**大组按瞬间收起**：8 张及以上的组按画面相似度分成几个「瞬间」（同一姿势或场景连拍的几张），每个瞬间里 AI 排名最高的
一张是代表。组信息里写「N 个瞬间」；比较表收起时只列各瞬间的代表和当前照片，代表行的「+N」是同一瞬间里另外几张，
「展开全部」看整组。代表和最好的另一个瞬间的代表并排比较；同一瞬间里的其它照片和本瞬间的代表比，差异句写「同一瞬间里」。
开启「决定后自动跳到下一张未决定」时，先跳本组还没决定的下一个代表，代表都定了再按原来的顺序走。
「本组操作 › 选中代表」在 Eagle 里只选中各瞬间的代表，方便并排看。只改显示和跳转顺序，排名、AI 建议和分组都不变；
剩下的相似照片可以用「按 AI 建议」一次定完。
下一阶段的筛片方向（图上标注、大组拆分提示）见 [culling-ux-direction.md](culling-ux-direction.md)。

星级同步和实时写回由检查器处理，主窗口设置保存原有共享 localStorage 键。
首次读取的 Eagle 星级只作基线，之后的变化才记为决定，避免把挑片前已有的星级误读为本次决定。
5★ 是精选、3★ 是候选、1★ 是淘汰（4★ 算精选、2★ 算淘汰），0 清除。
「留存」（R）给记录生活、纪实这类不比画质的照片：保留下来，但不参与评定和偏好学习，批量淘汰也不会动它。
它在 Eagle 里是一个「留存」标签（只写资源库，不改照片文件）；在 Eagle 里自己加这个标签也算留存，去掉标签或「恢复 AI」即清除。

还没分析完的照片也能先决定：检查器按钮、快捷键、在 Eagle 里打星或加「留存」标签都照常生效，检查器显示「尚未分析 · 已记下：精选」。
分析完成后这些决定自动并入，之后就和分析后做的决定一样；分析里已有更新的决定时以新的为准。
决定只以星级保存；AI 标签是设置里的可选项，默认关闭。开启后标签写入 Eagle 资源库元数据，不改照片文件，
可在分析记录里预览、确认及撤回；检查器的 AI 内容标签按钮也只在开启时出现。

分析记录每行的「报告与清理…」打开这条记录的页面：已决定数量、CSV / JSON 报告、「淘汰的移入回收站…」；
开启 AI 标签时还有「预览写回更改…」，已写入的标签即使关闭开关后也能撤回。

## 7. 窗口与布局

插件不再自动最大化或缩回窗口。布局只按窗口宽度切换：

- 首页单栏居中，主卡片最宽约 48rem，窄窗口适合与 Eagle 并排使用。
- 设置、分析记录和记录页面最宽约 53rem，按可用宽度排布。
- 照片查看和挑片在 Eagle、右侧检查器或宽屏检查器中完成。

插件记住用户最后一次的窗口大小并在下次打开时恢复。

## 8. 挑完之后

决定在挑的同时已经保存为 Eagle 星级，没有单独的“完成”或“写回”步骤。需要时在「设置 › 分析记录」打开一条记录：

1. 统计：精选、候选、淘汰、未挑。未挑的照片回到 Eagle 继续挑选。
2. 淘汰的移入回收站：只移动用户标为淘汰的照片（RAW+JPEG 一起），AI 建议淘汰但未决定的不动；先列出数量和文件名，输入 `MOVE_TO_TRASH` 后执行，可在 Eagle 回收站恢复。
3. 导出报告（CSV / JSON）。
4. 开启 AI 标签时：写回 AI 标签，说明会改什么和不会改什么（原片、人工星级、人工标签、文件夹）；先预览再确认，可撤回。

## 9. 设置

分为六组：分析（全速模式、随 Eagle 启动服务、空闲预处理）、保存到 Eagle（星级说明；同时使用 AI 标签及实时写回标签，默认关闭）、分析记录、存储（缓存上限与清理）、关于（版本与更新）、高级（服务地址、仓库路径、诊断）。
