# 使用场景与交互设计（v1.3）

本文从摄影师的使用习惯出发，定义插件的核心对象、每种状态下界面给什么、再次打开时如何接上上次的工作，以及无法接续时怎么办。界面实现以本文为准。

## 1. 摄影师怎么挑片

- 一次拍摄是一个工作单位：导入 Eagle 后通常放在一个文件夹里（按日期或主题），挑片也按这一批来做。
- 挑片经常被打断：先挑一部分，吃饭、睡觉、第二天再接着挑；大型拍摄（婚礼、活动）要分好几次才能挑完。
- 回来时最想要的是“回到我停下的地方”：同一批、同一组、同一张、同样的筛选。
- 同一批会变化：补导第二张卡、删掉明显废片、在 Eagle 里改了标签。
- 挑完要让结果在 Eagle 里可见（标签、星级、智能文件夹），之后在 Eagle 里继续修图或交付。
- 机器状态会变：服务被更新重启、电脑睡眠、Eagle 退出、插件窗口被关掉。这些都不能让已经做的选择丢失。

## 2. 核心对象：任务

用户心里的单位不是“一次运行”，而是“这一批照片的挑片工作”。界面统一称为**任务**。

- 任务 = 范围 + 最新一次分析 + 人工决定 + 写回状态。
- 范围有三种：一个文件夹、一组选中的照片、整个资源库。范围用稳定的键识别：`folder:<文件夹 ID>`、`selection:<照片 ID 摘要>`、`library`。
- 同一范围再次分析（补充新照片、更新分析、旧记录无法续跑后重做）生成同一任务的新版本：**之前的人工决定按照片自动带到新版本**，旧版本标记为“已被新版本取代”，默认不在列表中显示。
- 人工决定按拍摄单元保存（`unit:<主文件 ID>`），只要照片还在，换版本、换范围都能对上。

## 3. 任务的状态与首页动作

首页始终只有一个主按钮，取决于当前最该做的事。

| 状态 | 用户看到 | 主按钮 | 其他 |
|---|---|---|---|
| 分析中 | 进度、阶段、剩余时间；可以关窗口，完成后通知 | 无（进度卡就是主体） | 取消 |
| 已中断（服务重启、电脑睡眠、更新） | “上次分析在 65% 中断，已完成的部分会复用” | 继续分析 | 删除任务 |
| 已取消 | “已暂停在 40%” | 继续分析 | 删除任务 |
| 失败 | 用人话说明原因 | 重试 | 连续失败时显示诊断与日志位置 |
| 无法续跑（缺少续跑记录、旧版本格式） | “这条记录无法从中断处继续” | 按原范围重新分析（决定会带上） | 删除任务 |
| 原范围找不到（照片记录丢失、资源库不同） | “找不到原来的照片范围” | 在 Eagle 重新选择后分析（决定会自动带上） | 删除任务 |
| 待挑选 | “还剩 5 / 12 组 · 上次看到第 7 组” | 继续挑选 | 写回已挑部分 |
| 挑完待写回（未开实时写回） | “12 组已挑完，尚未写回 Eagle” | 写回 Eagle | 导出报告 |
| 已写回 | 写回时间 | 打开 | 撤回写回 |
| 写回后又改过 | “有改动尚未写回” | 再次写回 | 打开 |
| 范围新增照片（文件夹多了照片） | “文件夹新增 8 张” | 补充分析（只算新增，决定保留） | 先挑已有的 |

照片在 Eagle 中被删除：审阅时隐藏这些照片并提示数量；写回时跳过并在结果中列出。

## 4. 打开插件时显示什么

打开插件的瞬间，Eagle 里的选择代表用户此刻的意图。首页按以下顺序决定主卡片：

1. **服务未运行**：自动启动；失败时主按钮是“启动服务”，诊断折叠在下面。服务不可用时不显示需要服务的按钮。
2. **有分析正在进行**：进度卡。
3. **当前选择（文件夹或照片）已经属于某个任务**：
   - 完全覆盖：显示该任务的状态与对应主按钮（继续挑选 / 写回 / 继续分析）。
   - 有新增照片：主按钮“补充分析 N 张新照片”，次要“先挑已分析的”。
   - 只是任务的一部分：主按钮“在任务中查看这 N 张”。
4. **当前选择是新的**：主按钮“分析这 N 张”，显示预计耗时（已分析过的照片会复用）。
5. **什么都没选**：提示在 Eagle 里选文件夹或照片；如果有未完成的任务，主卡片是“继续上次的任务”。整库分析只作为次要按钮，显示张数与预计时长，点击后确认。

任务列表在主卡片下面，按“需要处理的”排序：分析中、待挑选、待写回、可继续分析，然后是已完成。每行显示状态、进度和对应的按钮。只显示当前资源库的任务。

## 5. 审阅会话的连续性

- 每个决定立即保存在本机服务中，与窗口、插件、Eagle 是否关闭无关。
- 每个任务记住审阅位置：筛选、组、组内照片、视图。重新打开时直接回到原处，并提示“回到上次的位置：第 7 组”；如果那一组已不存在（分组修正、补充分析后），回到第一个未挑完的组。
- 撤销记录只在当前会话内有效；跨会话可以直接改决定。
- 补充分析或重新分析后打开新版本：已挑过的照片保持原决定，新照片标为未挑，默认先看未挑完的组。

## 6. 挑片方式

摄影师挑片的习惯差别很大，插件提供两类入口，第一次默认是 Eagle 原生方式，之后记住用户上次用的方式。

**在 Eagle 中挑（默认）**：照片在 Eagle 自己的网格和查看器里看，插件窗口是一个紧凑遥控器，右侧检查器显示当前照片的分析、组上下文和决定按钮。遥控器显示总进度、按“未决定 / 没把握 / 建议淘汰 / 有问题”筛选（带数量），1/2/3/0 记录决定，←/→ 切换、↓ 下一组，可选“决定后自动下一张”和“跟随 Eagle 选中”。AI 建议标签只有用户为当前任务开启后才写入 Eagle 资源库，不改照片文件，可随时撤回或一键清除插件写入的全部 AI 标签。旧版 Eagle 没有 `item.select` 时会明确提示需要手动点选。

**在插件里专注挑片**：一个队列驱动的全屏视图，同一份决定数据，四种方式随时切换：

- **逐张**：单张大图（按窗口尺寸取高清显示图）+ 胶片条，1/2/3/0 决定后自动下一张（可关），←/→ 切换，↑/↓ 跳组，N 下一张未决定。大图本身可滚轮缩放、放大后拖动，双击或 Z 在适应窗口与 100% 之间切换，+/− 逐级缩放，Esc 回到适应窗口；放大时自动升高显示档，超过显示档后按可见区域读取原始像素。胶片条可用滚轮横向滚动。空格全屏查看。
- **网格**：缩略图批量处理，单击选中、Shift 连选、⌘/Ctrl 点选、⌘A 全选本页，1/2/3/0 作用于所有选中照片；双击或 Enter 进入逐张。
- **AI 先挑**：输入要保留的张数，按“每组最佳优先、再按分数”排出保留线，只列出保留线附近、有问题或没把握的照片让人确认；其余可一键“按 AI 结果确认”（二次确认，不覆盖已手动决定的照片）。
- **分轮**：第 1 轮只看建议淘汰和有问题的照片（去废片）；第 2 轮进入组内并排比较选每组最好的（复用原审阅页，返回时回到分轮）；第 3 轮逐张复核精选。

筛选和方式切换时列表在进入时固定，决定只更新标记，不会让照片在眼前消失。每个任务记住方式、筛选、轮次、目标张数和当前位置。

**查看调整**（逐张视图按 A）：曝光、对比度、高光、阴影、色温、色调、饱和度和自动曝光，可“用到本组”，按住 `\` 看调整前。调整只影响显示：参数按任务保存在本机服务（`adjustments.json`），不改原片、不导出、不参与评分。曝光、白平衡和饱和度在线性光下计算，对比度、高光和阴影用平滑单调曲线。

**清晰度**：大图、比较卡片和逐张视图都按显示尺寸向服务请求 1024/2048/3072/4096/6144 档的显示图（不放大原图），放大时自动升档。RAW 优先用足够大的内嵌预览，不够时解码；HEIC/HEIF 在 macOS 用系统解码，Windows 用微软商店的 HEIF/HEVC 扩展（WIC），Windows RAW 在其它方式失败时用 Raw 图像扩展。降级到 Eagle 缩略图时会标明“低清”，服务重启后会重新尝试解码。

## 7. 窗口与布局

插件不再自动最大化或缩回窗口。布局只按窗口宽度切换：

- **窄（< 560px）**：首页单栏；专注挑片顶栏两行，决定按钮占满底部，调整面板从底部弹出。适合与 Eagle 并排使用。
- **中（640–1100px）**：首页两栏；审阅为组内并排比较 + 底部操作条，照片信息按需展开。
- **宽（> 1100px）**：首页两栏；审阅为三栏：组列表、比较区、当前照片信息。

插件记住用户最后一次的窗口大小并在下次打开时恢复；审阅页提供“放大审阅”按钮，点了才最大化，再点还原。

## 8. 完成与写回

“完成”页按顺序给出：

1. 本任务统计：精选、候选、淘汰、未挑。
2. 有未挑的照片时：回去挑完，或按建议处理剩余（只处理未挑的，可撤销）。
3. 写回 Eagle：说明会改什么（AI 标签、可选 5 星、可选智能文件夹）和不会改什么（原片、人工星级、人工标签、文件夹）；先预览再确认；移入回收站需要二次确认。
4. 导出报告（CSV / JSON）与撤回写回。

## 9. 设置

分为五组：分析（全速模式、随 Eagle 启动服务、空闲预处理）、写回（实时写回、星级、智能文件夹）、存储（缓存上限与清理）、关于（版本与更新）、高级与实验（服务地址、仓库路径、诊断、个性化）。默认值不变。
