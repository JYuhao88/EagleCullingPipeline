# v1.9.0 发布说明

新增「留存」：记录生活、纪实这类不比画质、只想留下来的照片，可以单独标出来，既不会被淘汰掉，也不会影响后面的评定和学习。
分析、评分、排序、规则、分组、依赖与 lockfile 均未改变。

## 留存

- 检查器决定按钮新增「留存」（快捷键 R），和精选、候选、淘汰并列；选别的决定会替换它，「恢复 AI」清除它。
- 留存在 Eagle 里是一个「留存」标签，星级设为 0。标签只写 Eagle 资源库，不改照片文件。
- 在 Eagle 里自己给照片加上「留存」标签也会被识别为留存；去掉标签只清除留存，不会动其它决定。
- 「其余淘汰」、闭眼/模糊批量淘汰、「未定的全按 AI 建议」、重新分析后的继承都把留存当作已决定，不会改动它。
- 回收站只处理淘汰的照片，留存的照片不会被移走。
- 进度和完成面板显示留存数量。

## 不影响评定

- 偏好学习把留存的照片从所在组里拿掉，不当作“输给首选”的样本。
- 抽查评估的标签、配对样本和准确率计算同样排除留存的照片。
- 开启 AI 标签时，写回会保留「留存」标签，不把它当作 AI 标签替换或撤回。

## 验证

- 单元测试覆盖留存的保存、替换与清除，Eagle 标签双向同步及两个窗口互相回声，批量操作跳过，学习与抽查评估排除，标签写回保留。
- 在检查器样例中确认 320 像素窄栏下五个按钮排成一行，按钮与 R 键都能标记，选淘汰会替换留存。
- 全部测试与公开发布检查通过。
