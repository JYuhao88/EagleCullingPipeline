# v1.7.1 发布说明

哈苏 3FR 和理光 DNG 的显示改用相机自己的 JPEG，颜色与机内 JPEG 一致。只影响显示，
分析取图、评分、排序、规则、分组、依赖与 lockfile 均未改变。

## RAW 显示

- 哈苏 X2D II 的 3FR 把机内 JPEG（3888×2918，HNCS 色彩）存为主图，标准预览标签里没有；现在直接读取这张 JPEG。
- 理光 GR IIIx 的 DNG 有两张预览：全尺寸 6000×4000 的机内 JPEG 和 54 KB 的小图。以前取到的是小图，
  在 Mac 上因此显示失败，在 Windows 上退回通用 RAW 解码；现在取最大的那张。
- 索尼 ARW 本来就用全尺寸机内 JPEG，不变。
- 以前缓存的 RAW 显示图会重新生成一次；从 RAW 通用解码得到的中尺寸缓存不再用于显示，以免盖住机内颜色。
- 没有可用机内 JPEG 的 RAW 仍按原来的顺序：同名 JPEG、rawpy 解码、Windows 系统解码、Eagle 缩略图。

## 验证

- 单元测试覆盖最大预览的选择和 IFD0 JPEG 的识别。
- 在两台机器的资源库里按格式抽样，直接调用服务的显示取图：3FR、DNG、ARW 都得到机内 JPEG。
- 全部测试与公开发布检查通过。
