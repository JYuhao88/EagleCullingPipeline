# v1.5.0 发布说明

Eagle 右栏的选片面板新增本机 AI 观察、照片之间的具体差异、美感参考分、AI 内容标签和「按我的口味调整」。
默认排序、规则、评分权重和分组算法未改变；观察、美感分和内容标签只用于显示与手动写回。依赖与 lockfile 未变。

## 本机 AI 观察

- 从已有的姿态、人脸和人物信号推出：背景有人、同尺度合影、正脸／侧脸、手在脸旁、闭眼、对焦点落在眼睛上。
- 本机分类头：笑、嘴张开、看镜头。人脸小于训练数据时不下结论，不把「没检测到」当作否定。
- 观察只在右栏显示，不参与排序，也不写入照片文件。

## 照片之间的具体差异

- 与同组竞争照片相比，右栏最多给出三句具体差异（眼睛、裁切、清晰度、主体亮度、面部高光、倾斜，以及上面的观察），
  替代原来的分差句；没有可靠差异时仍显示分差。
- 对比表：排名列变窄，新增睁眼程度、脸部大小和与最佳照片的相似度；悬停显示文件名和理由；美感列始终显示。
- 可折叠的「细节与曝光」：主体脸适应窗口／2 倍／4 倍查看，-3 到 +3 EV 的仅查看曝光调整，不改原图和评分。

## 美感参考分

- 基于本机 DINOv2 嵌入的轻量美感分，只作参考显示，不进排序。

## 本机 AI 内容标签

- 人数、景别、横竖构图、模糊／过曝／欠曝／闭眼、焦段，以及 32 个场景标签（海边、街道、夜景等），统一使用 `AI·` 前缀。
- 只在手动操作时写入 Eagle，可一键清除；Eagle 本地接口按端点自动兼容旧版本，并支持清除星级。

## 按我的口味调整

- 右栏显示按你的选优决定学到的情况、留出一致率和最影响的因素；确认后只调整剩余未决定的组，可撤销。

## 需要的本机模型

场景标签和三个分类头使用 CLIP ViT-B/32 视觉模型（MIT 许可证，约 89 MB）。首次使用前在插件目录执行：

```sh
node scripts/download-clip.mjs
```

脚本从公开的 Hugging Face 固定版本下载并校验 SHA-256。看镜头还会用到已有的 MediaPipe 人脸模型和 Python 环境。
模型缺失时这些功能不显示，也不影响其它分析。

## 验证

- macOS 完整回归通过，公开检查 0 命中；在本机 Eagle 右栏实测观察与对比句。
- 内容标签写入与清除由模拟 Eagle 接口的测试覆盖，尚未在真实 Eagle 中验收。
- Windows 通过自动更新的候选服务健康检查把关，失败会自动回退；Windows CPU 上量化 CLIP 每张脸约 14 毫秒。
