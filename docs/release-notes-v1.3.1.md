# v1.3.1 发布说明

修复放大窗口后界面不跟着放大、逐张挑片不能缩放的问题，并让“清除 AI 标签”能清掉旧版本写入的标签。排序、规则、评分模型和分组算法未改变，依赖与 lockfile 未变。

## 大窗口

- 界面按窗口尺寸整体放大：宽于约 1360/1760/2360 像素（且高度足够）时，文字、按钮、缩略图和面板分别放大到 1.15/1.3/1.6 倍；普通窗口与之前一致。
- 在 Eagle 中挑（遥控器）在宽窗口改为左侧大图占满高度、右侧决定与导航；大图按显示尺寸取高清图，不再拉伸小缩略图。
- 专注挑片和遥控器铺满窗口，底部操作条不再被裁掉一截；顶栏和底栏多余的空白去掉。

## 逐张挑片可以直接放大

- 大图可滚轮缩放（以指针位置为中心）、放大后拖动；双击或 Z 在适应窗口与 100% 之间切换，+/− 逐级缩放，Esc 回到适应窗口；右下角显示缩放比例。
- 放大时自动升高显示档，超过显示档后按可见区域读取原始像素（与全屏查看相同）；查看调整在放大时同样生效。
- 胶片条显示前后各 60 张，可用滚轮横向滚动；当前照片保持在中间。
- 空格仍是全屏查看。

## Eagle 标签

- “清除插件写入的全部 AI 标签”现在也会清除早期版本写入的标签（AI原片、AI已配对、AI配对待确认、AI未配对原片、AI可能模糊、AI低分辨率、AI待淘汰、待复核）。你自己加的标签不受影响，未知的 AI 开头标签也不会被删。
- 修复部分 Eagle 版本对带字段筛选的列表请求返回 HTTP 500，导致清除标签失败的问题：遇到这种情况自动改用不带筛选的请求。

## 验证

- macOS 完整回归通过，公开检查 0 命中；1280/1920/2560 宽及 1440/1024/800/420 宽、明暗主题下用浏览器实测缩放、拖动、快捷键、胶片条滚动和决定保存。
