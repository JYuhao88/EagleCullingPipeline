# v1.11.0 发布说明

分析还没跑完也能先打分、打标签：先挑出来的照片不用等分析，分析完成后这些决定自动并入。
分析、评分、排名、AI 建议、规则、分组、依赖与 lockfile 均未改变。

## 分析前的决定

- 选中一张还没分析的照片，检查器里的精选、候选、淘汰、留存、恢复按钮和快捷键（数字键、R）都可以用，
  状态写「尚未分析 · 已记下：精选」，按钮亮起当前的决定；多选时一次全部记下。
- 在 Eagle 里直接打星或加、去「留存」标签也一样会记下，不再被忽略。
- 这些决定存在本机分析服务的数据目录里，不写照片文件，也不写 Eagle 标签之外的东西；「恢复」即可删除。
- 第一个覆盖这张照片的分析完成时自动并入，之后和分析后做的决定一样：会出现在检查器、进度和学习里。
  如果这次分析从上一批继承到更新的决定，以更新的为准。RAW 和 JPEG 配对时取两者中最后一次的决定。
- 后台预取不会并入，正式分析完成时才并入。

## 验证

- 端到端测试：分析前在两张照片上分别打星、加「留存」，另一张打了又恢复，分析完成后恰好并入两条，
  检查器读到「已人工决定」，待并入列表清空；Eagle 里同一颗星的重复上报不算新决定；超长理由被拒绝。
- 并入规则测试：已有更新决定时不覆盖，同一拍摄单元取最新一条，其它资源库和本次未覆盖的照片继续等待。
- 检查器测试：未分析照片按数字键、R、0 后立即显示已记下的决定，并按服务返回的结果刷新。
- 全部测试与公开发布检查通过。
