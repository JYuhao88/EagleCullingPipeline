# v1.4.0 发布说明

挑片界面整体搬进 Eagle 右栏（检查器），决定改用 Eagle 星级记录。排序、规则、评分模型和分组算法未改变，依赖与 lockfile 未变。

## 在 Eagle 右栏挑片

- 选中照片后，右栏顶部显示「Eagle照片筛选」：当前照片的 AI 建议、组内名次、与本组第一名的差距和原因。
- 精选 / 候选 / 淘汰 / 恢复 AI 一键决定；上一组、下一组、跳到未定组或没把握的组。
- 组内对比表：缩略图、综合分、清晰度、眼神、曝光、闭眼人数等，只显示组内有差异的列；大组折叠为关键行（前三、当前前后、最后一名），可展开全部。
- 分数分布条和「保留前 N 张、其余淘汰」；整组接受 AI、按任务批量决定。
- 可选在缩略图上标出人脸（闭眼标红）和人体姿态。
- 在右栏点同组其他照片，原地切换，不再整块闪白、不再把右栏滚回顶部；RAW+JPEG 只选主文件，Eagle 不会切到多选预览。
- 主窗口保留设置、分析、任务列表和完成后的写回；旧的审阅页、专注挑片和插件内查看器已移除。

## 用星级记录决定

- 精选 5 星、候选 3 星、淘汰 1 星；在 Eagle 中间按 5/3/1 直接打星，右栏同步显示。
- RAW 与 JPEG 星级同步。

## 其他

- 插件 id 改为 `eagle-culling`（Eagle 无法复用带点 id 的检查器视图）。从旧版本更新后，右栏区块第一次会出现在「注释」下方，再次启动 Eagle 后回到顶部。
- macOS：服务自动启动可以找到 Dock 启动时不在 PATH 里的 Node，启动失败时会提示。
- 插件代码更新后页面自动重新加载。
- 宽窗口首页预览铺满；默认不打开开发者工具。

## 验证

- macOS 完整回归通过，公开检查 0 命中；在本机 Eagle 4.0 中实测右栏位置、对比表和标记。
