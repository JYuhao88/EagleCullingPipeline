# v1.12.1 发布说明

修正「细节与调节」里竖拍照片横过来的问题；没分析的照片也能用「细节与调节」。
分析、评分、排名、AI 建议、规则、分组、依赖与 lockfile 均未改变。

## 竖拍照片不再横着显示

- 用 RAW 里的机内 JPEG 生成高清显示图时，方向被转了两次、第二次又抵消了第一次，
  竖拍的 RAW 在「细节与调节」和对比图里会横过来；Windows 上更常见。
- 已修正；以前缓存的 RAW 显示图会在第一次查看时重新生成一次。

## 没分析的照片也能看细节、调节

- 选中一张还没分析的照片，检查器里照样有「细节与调节」：放大、对焦框、合焦高亮、曝光等调节都能用。
- 图直接从资源库读原图（RAW 用机内 JPEG），不需要等分析。
- 调节值先按这张照片记下，分析完成后自动沿用；之后再调或复位，以新的为准。只影响显示，不改原图、星级和评分。

## 验证

- 真实竖拍 ARW（方向 6 和 8）的机内 JPEG 显示为竖图；带 EXIF 方向的 JPEG 只转一次。
- 没分析的照片：显示图、对焦点、调节的读写和错误输入；分析后沿用调节值，复位后不再回来。
- 检查器：没分析的照片用条目地址取图、读写调节。
- 全部测试与公开发布检查通过。
