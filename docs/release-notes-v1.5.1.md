# v1.5.1 发布说明

修复 Eagle 右栏较窄时选片面板显示拥挤的问题。排序、规则、评分权重、分组算法、依赖与 lockfile 均未改变。

## 右栏宽度

- Eagle 右栏默认约 240 像素宽，插件无法自行设置宽度；向左拖动右栏左边缘可加宽到约 600 像素，Eagle 会记住这个宽度。
- 对比表按右栏实际宽度决定显示几列：放不下时先保留总分、睁眼／闭眼、眼部、美感、清晰、画质，其余列收起，
  表下方说明哪些列未显示以及如何加宽。拖宽或拖窄右栏后，对比表自动重排。
- 「保留前 N 张」一行在窄栏下整体换行，按钮文字不再被逐字折断。

## 验证

- 单元测试覆盖列宽计算、窄栏保留与收起的列、未显示说明的出现与消失。
- 面板夹具中检查了 240、480、600 像素宽度，以及在页面内直接改变宽度后的自动重排。
- 全部测试与公开发布检查通过。
