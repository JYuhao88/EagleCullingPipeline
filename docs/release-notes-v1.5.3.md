# v1.5.3 发布说明

从 Eagle 插件菜单打开插件，直接进入宽屏检查器；主界面通过「返回主界面」进入。只改界面；排序、规则、评分权重、分组算法、
依赖与 lockfile 均未改变。

## 打开方式

- 从插件菜单打开「Eagle照片筛选」：插件窗口显示宽屏检查器并最大化，跟随 Eagle 里选中的照片。
- 宽屏右上角「返回主界面」：回到主界面和原来的窗口大小，在那里分析、写回、改设置；主界面顶栏的「宽屏检查器」再回到宽屏。
- 主界面正在提交任务、写回或有对话框打开时，从菜单打开不会打断，只提示稍后再点「宽屏检查器」。
- 宽屏里没选照片时提示「在 Eagle 里选中照片后显示」；选中的照片还没分析时提示点「返回主界面」去分析。

## 关闭窗口之后

- 关闭宽屏窗口后，插件在后台回到主界面：分析服务、自动更新、空闲预处理、分析完成通知和 Eagle 打星记为决定都照常运行。
  回到主界面时不改窗口大小，避免窗口被重新弹出；下次从菜单打开仍是宽屏。
- 有尚未保存完的决定或实时写回时，先等它们完成（最多约 5 秒）再切换。
- 插件在后台检测到代码变化并自动重新加载时，不会把隐藏的窗口显示出来。

## 验证

- 单元测试覆盖：页面加载时 Eagle 自带的那次「打开」事件与真正从菜单打开的区分、隐藏状态下加载不显示窗口、关闭宽屏后回到
  主界面且不改窗口大小、「返回主界面」恢复窗口、宽屏空状态提示。
- 面板夹具中模拟 Eagle 事件走完整流程：主界面 → 菜单打开进宽屏 → 宽屏中再次打开保持宽屏 → 关闭后回到隐藏的主界面 →
  再打开进宽屏 → 返回主界面后保持主界面；对话框打开时不切换，仅输入框残留焦点时照常切换。
- 全部测试与公开发布检查通过。
