# v1.4.1 发布说明

修复在 Eagle 右栏切换照片时缩略图闪烁，并让中间网格跟着定位到选中的照片。排序、规则、评分模型和分组算法未改变，依赖与 lockfile 未变。

## 右栏切换不再闪

- Eagle 每次切换选中都会重新加载右栏页面。现在页面保存的画面里自带缩略图，重新加载后第一帧就完整显示，原图加载完成后再无缝替换。
- 打开一组时，组内所有照片的预览会在后台预先加载；在右栏点同组任何一张，新出现的行和对比大图都不再先空一下。

## 中间网格跟着定位

- 在右栏（以及主窗口的「在 Eagle 中挑」）选中照片后，中间网格会滚动到这张照片；照片已在可视范围内时不滚动，不切换文件夹，也不清除筛选和搜索词。

## 验证

- macOS 完整回归通过，公开检查 0 命中；在本机 Eagle 4.0 中实测右栏切换和网格定位。
