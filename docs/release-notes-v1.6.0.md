# v1.6.0 发布说明

挑片结果只以 Eagle 星级保存，AI 标签改为设置里的可选项（默认关闭）；主界面不再显示任务列表。
排序、规则、评分权重、分组算法、依赖与 lockfile 均未改变。

## 结果保存为星级

- 精选 5 星、候选 3 星、淘汰 1 星，存在 Eagle 资源库里，不改照片文件；在 Eagle 里改星或清零即可撤销。
- 「设置 › 保存到 Eagle › 同时使用 AI 标签」默认关闭。关闭时不写 `AI精选` / `AI候选` / `AI淘汰` 标签，
  检查器里也不出现 AI 内容标签按钮。
- 实时写回标签只在开启 AI 标签后可用；以前打开过实时写回的，升级后在开启 AI 标签前不再写标签。
- 去掉两个选项：「智能文件夹」（实际从未生效）和「实时写回时设 5 星」（星级本来就一直写入）。
- 以前写入的 AI 标签即使关闭开关，也能在分析记录里撤回。

## 主界面

- 首页只有一张卡片：开始分析、分析进度，或接着上次挑选。不再列出以前的任务，也没有「完成」面板。
- 以前的分析在「设置 › 分析记录」，每条可继续挑选或继续分析；「报告与清理…」打开这条记录，
  显示已决定数量、CSV / JSON 报告和回收站清理。
- 全部决定后显示「已挑完」，不再提示「待写回」。

## 回收站清理

- 「淘汰的移入回收站…」只移动你标为淘汰的照片（RAW+JPEG 一起）；AI 建议淘汰但你没有决定的照片不动。
  以前在写回对话框里勾选回收站，会把这些照片也一起移走。
- 先列出照片数和文件名，输入 `MOVE_TO_TRASH` 后才执行；已不在资源库的文件会跳过。可在 Eagle 回收站恢复。
- 无法确认当前 Eagle 资源库时，不移动任何照片。
- 服务新增 `POST /runs/:id/trash-rejected`。

## 验证

- 单元测试覆盖：回收站只移人工淘汰（含配对文件）、跳过缺失文件、资源库无法确认时拒绝；
  AI 标签关闭时检查器和实时写回不写标签；首页单卡片、分析记录与记录页面。
- 面板夹具中目视检查首页、设置、分析记录、记录页面和检查器。
- 全部测试与公开发布检查通过。
