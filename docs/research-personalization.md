# 根据使用持续更新选片模型：个性化调研与设计建议

> 调研日期：2026-10-11。目标是本地运行、面向一年粗选数万张的职业/重度摄影师。本文把厂商页面上的能力描述与用户报告分开；“未公开”不等于“不存在”。产品页面会改版，链接是复核入口。

## 结论先行

1. 商业软件普遍把“相似组、闭眼/模糊、表情和曝光”作为通用筛选，把个性化更多放在修图风格；公开资料很少给出达到稳定个性化所需的张数、算法或是否跨项目训练。不要把“AI learns your style”当作可重复的样本承诺。
2. 对选片最适合的是冻结通用特征、只训练很小的个人排序头。组内 pairwise 的 Bradley–Terry/逻辑回归可在几十到几百个高质量比较后开始工作；这只是工程起步门槛，论文并未证明对本产品、每个题材都成立。
3. AI 建议会改变用户看见和选择的分布。批量接受、卡片位置和默认勾选都是有偏的隐式反馈；日志必须保存展示顺序、曝光、建议、用户改动和操作方式，才能事后做倾向性加权或只使用强信号。
4. 评估必须按时间或整组留出，报告学习曲线、bootstrap 区间和非个性化基线。模拟用户只能验证管线和漂移检测，不能替代真实摄影师。

## 3. 反馈回路、偏差与日志

用户先看到 AI 排序再做选择会产生锚定/自动化偏差；第一张、居中卡片和默认勾选有位置偏差；一键“接受全部”只说明用户当时信任或赶时间。把这些动作当作同等强的正例会让模型自我强化并逐渐漂移。

适合选片的去偏组合是（推荐系统方法见 [Joachims et al., WSDM 2017](https://doi.org/10.1145/3018661.3018697)）：

- 少量随机化首屏顺序或在相似组内打散位置，保留 `display_rank`、`shown_at` 和可见时长；
- 以“改动 AI 建议”作为最高权重，明确首选/淘汰次之，批量接受只作低权重；撤销、跳过、平局不能伪造负例；
- 每隔一小部分组保留人工基线/对照组，或让用户先在少数组中盲选再显示建议；
- 训练时做倾向性加权（例如按被展示/被接受概率的逆概率），概率估计不足时宁可只用强信号；
- 按题材、客户、profile 分层，防止把客户交付标准混进个人创作风格。

每条事件至少记录：事件 ID、时间与时区、库/项目/profile、run/model/权重快照、组 ID 与成员内容哈希、候选在展示时的排序和是否进入视口、AI 对每候选的分数/建议/理由、用户动作（keep/reject/winner-change/tie/skip/undo）、是否批量、是否改动建议、理由/category、操作耗时、客户端版本、写回/删除结果和墓碑关联 ID。特征库另存抽取器版本、缺失原因和原图是否仍可取；不要把不存在的对焦信号编码成 0。

## 4. 小样本可信评估

按拍摄会话或时间切分：训练只能看过去事件，测试整组来自未来会话；同一连拍不能跨 train/test。至少报告 pairwise accuracy/AUC、组内 top-1、NDCG@k 或 Kendall tau，并给 bootstrap（按组重采样）95% 区间、有效组/对数和 tie 比例。与通用 L0、未个性化四指标头、简单“组中心/清晰度”基线比较。

画学习曲线（按新增组数的性能和区间），预先约定“提升超过基线且区间不跨零”的停止规则。若样本少于门槛，输出“不足以判断”，不要输出 0% 或“已学会”。模拟用户应使用隐藏偏好生成选择、切换偏好后验证漂移和衰减；它不能模拟真实的注意力、赶时间、客户约束和锚定，所以必须再做真实会话回放。

## 6. 证据等级与实施顺序

**强证据**：本轮可直接核验的产品页功能、PARA/LAPIS 的数据规模与属性消融摘要、时间/整组留出、防止训练集自评。**中等证据**：冻结通用特征后使用低参数排序头、记录曝光并做随机对照。**未核实/推测**：每用户 10/50/100 的稳定门槛、50–300 对阈值、商业产品的本地训练与跨项目隔离、主动学习节省量、UI 随机化对摄影师效率的影响。

建议顺序是：先上线版本化特征库和完整事件日志；再以默认关闭的 L1 做时间切分回放；确认有足够强信号后加入 profile/衰减和复核提示；最后才评估主动学习或任何 LoRA。所有本地推理保持小模型和特征头，商业产品宣传中的云端/大模型能力不作为本项目依赖。

### W8 第二轮：漂移提示的检验对象

对相邻、不重叠的两个最近 N 组窗口（默认各 25 组），使用固定旧 head 计算 top-1 一致率。
提示要求下降至少配置值（默认 0.2），并且对两个窗口独立重采样 2000 次得到的一致率差
单侧 95% percentile bootstrap 下界 > 0。直接检验差值比要求两个边际双侧 95% 区间
完全分离更符合“是否下降”的问题；后者在 0.60→0.24 时仍可能不触发。应用门槛仍是
两个时间／内容隔离切分的配对提升区间下界均 >0，没有改动。漂移只提示、不自动训练或应用。

小窗口 bootstrap 是实用近似，反复查看窗口不是多重检验校正，也不是分布无关的在线报警保证。
模拟报告分别列出真实浏览器稳定期查看次数／误报率，以及固定 seed 的函数层平稳 Bernoulli
窗口校准（不能称为浏览器动作或真实摄影师误报率）。仍需真实会话与不同一致率、窗口长度验证。
