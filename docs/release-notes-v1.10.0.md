# v1.10.0 发布说明

大组按「瞬间」收起：一组连拍二三十张时，检查器先给出几个代表，不用逐张从头看到尾。
只改检查器的显示和跳转顺序；分析、评分、排名、AI 建议、规则、分组、依赖与 lockfile 均未改变。

## 瞬间与代表

- 8 张及以上的组按画面相似度分成几个瞬间（同一姿势或场景连拍的几张），每个瞬间里 AI 排名最高的一张是代表。
  算法和之前在 Eagle 里试用的「AI·代表 / AI·同簇」相同。
- 组信息写「N 个瞬间」。比较表收起时只列各瞬间的代表和当前照片，代表行的「+N」是同一瞬间里另外几张，「展开全部」看整组。
- 汕头这批的 8 个大组：19 张收成 5 个瞬间，17→4，12→3，11→3，10→4，10→4，8→4，8→3。

## 比较与跳转

- 代表和最好的另一个瞬间的代表并排比较；同一瞬间里的其它照片和本瞬间的代表比，差异句写「同一瞬间里，……」。
  不分瞬间的组和以前一样：首选对第 2 名，其余对首选。
- 开启「决定后自动跳到下一张未决定」时，先跳本组还没决定的下一个代表；代表都定了再按原来的顺序走。
- 「本组操作」新增「选中代表」，在 Eagle 里只选中各瞬间的代表，方便在 Eagle 里并排看。
- 剩下的相似照片可以用「按 AI 建议」一次定完，已做的决定不变。

## 验证

- 在汕头这批上，新实现与试用脚本的分簇结果 8 组全部一致；每组计算约 1–2 毫秒，400 张的组约 130 毫秒，结果按组缓存。
- 单元测试覆盖分簇、代表与编号、没有画面特征的照片、比较表收起行、比较对象与差异句、决定后的跳转顺序。
- 在检查器样例里确认 320 像素窄栏下的收起表格、「+N」、四个本组按钮，以及决定首选后跳到下一个瞬间的代表。
- 全部测试与公开发布检查通过。
