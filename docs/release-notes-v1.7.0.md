# v1.7.0 发布说明

检查器的「细节与曝光」改为「细节与调节」：修正曝光在暗部的断层，增加 Lightroom 式的常用调节，
同时作用于对比的两张照片，并按照片保存。排序、规则、评分、分组、依赖与 lockfile 均未改变。

## 曝光更准确

- 以前用浏览器的线性光滤镜做曝光，Chromium 以 8 位保存线性中间值，暗部严重断层：
  实测 +1 EV 时暗部 0–63 只剩 14 级（应为 64 级），+3 EV 时 7–17 级全部变成同一级。
- 现在每个通道用 256 项查找表，从 8 位 sRGB 输入直接算到输出：与精确的线性光增益相比误差不超过 1 级，暗部不再合并。
- 「自动曝光」先把每个通道解码成线性光再加权，按看到区域的亮度中位数对到 18% 中灰。

## 更多调节

- 曝光（±3 EV）、对比度、高光、阴影、白色色阶、黑色色阶、色温、色调、饱和度（−100 到 +100）。
- 曝光和白平衡作用在线性光上，色温和色调不改变中性灰的亮度；对比度、高光、阴影和黑白色阶是单调的全局曲线，
  任何组合都不会让亮暗倒转。
- 双击某一行复位该项；「复位」清除全部；切到没调过的照片时可「沿用上一张」。

## 对比与保存

- 调节同时作用于细节图和对比的两张照片（右栏和宽屏都一样），标题旁显示「已调整」。
- 调节值按照片存到这次分析记录的 `adjustments.json`，下次打开还在；不写进照片、Eagle 星级或评分，「复位」即删除。
- 调整的是显示用的 JPEG 或机内预览：已过曝的高光不会恢复，高光/阴影是全局曲线，不是 Lightroom 的局部自适应。

## 验证

- 单元测试覆盖：各档曝光查找表与精确公式一致且暗部无合并；所有滑块组合下曲线单调；白平衡保持灰亮度；
  按照片读取、保存、沿用、单项与全部复位；同时保存多张照片不丢失。
- 在浏览器里用灰阶图实测旧滤镜与新查找表的输出；面板夹具中目视检查右栏布局与保存。
- 全部测试与公开发布检查通过。
