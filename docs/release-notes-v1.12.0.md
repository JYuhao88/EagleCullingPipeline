# v1.12.0 发布说明

一眼看清整个资源库哪些分析过、哪些没有，按文件夹排队分析；选中照片不再直接开始分析。
分析、评分、排名、AI 建议、规则、分组、依赖与 lockfile 均未改变。

## 资源库进度

- 首页主卡片下方「资源库进度 ›」打开资源库视图，按 Eagle 的文件夹树列出每个文件夹：
  ✓ 已分析、◐ 已分析 120/300、○ 未分析、排队第 N、分析中 54%；不在任何文件夹的照片单独一行。
- 每个没分析完的文件夹有「排队」和「选中未分析的 N 张」。后者只在 Eagle 里选中这些照片，方便先挑或检查，
  不写标签、不改文件夹。
- 「未分析的全部排队」一次排进所有没分析完的文件夹。

## 按文件夹排队

- 一个文件夹排一次，只算直接放在里面的照片，子文件夹各自排队；文件夹里的照片在轮到时才读取，中途新加的也算上。
- 一次只跑一个，跑完自动开始下一个；可以置顶、取消、清空，正在分析的那个不受清空影响。
- 队列存在分析服务的数据目录里，服务重启或更新后继续。空闲预处理永远排在最后。

## 选中照片只显示状态

- 在 Eagle 里选中照片或文件夹，主卡片只显示它们在哪个文件夹、分析到哪了，不会自动开始或排队。
- 要分析，点「排队「文件夹名」」；照片分布在多个文件夹时是「排队这 N 个文件夹」。
  只想分析选中的几张，在「更多」里点「只分析选中的 N 张」。
- 检查器里没分析的照片会显示「排队第 2：「汕头」」或「正在分析「汕头」 54%」；没分析完照样可以先打分、打标签。

## 验证

- 服务测试：用一个带嵌套文件夹、未归档、已删除和视频文件的假资源库，验证文件夹统计、选中位置、排队去重、
  重启后队列还在、置顶与取消、跑完自动接下一个、「未分析的全部排队」、检查器的排队位置和错误输入。
- 界面测试：选中照片不发出任何分析或排队请求；主卡片的排队、「更多」里的只分析选中的、资源库视图的排队、
  取消和全部排队都发出正确的请求；页面隐藏时不轮询。
- 全部测试与公开发布检查通过。
