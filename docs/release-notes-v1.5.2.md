# v1.5.2 发布说明

新增「宽屏检查器」：Eagle 右栏最宽只能拖到约 600 像素（Windows 高分屏上尤其显窄），现在可以把同一个检查器放到插件自己的窗口里，
窗口可铺满屏幕。只改界面；排序、规则、评分权重、分组算法、依赖与 lockfile 均未改变。

## 宽屏检查器

- 打开方式：点右栏顶部的「宽屏查看」，或在「Eagle照片筛选」插件窗口顶栏点「宽屏检查器」。插件窗口会切到检查器并最大化。
- 跟随 Eagle 里选中的照片，打星（5/3/1）、精选／候选／淘汰、跳组、本组操作、细节与曝光等与右栏相同。
- 窗口宽于约 960 像素时分两栏：左侧放大当前照片和对比照片（按照片自身比例，单张一组也放大显示），下方是细节与曝光；
  右侧是决定按钮、对比表和其余操作。大图先显示缩略图，清晰版加载好后替换。字号随窗口变大，对比表缩略图也随之放大。
- 「返回主界面」或从 Eagle 插件菜单再次打开插件，回到原来的主界面和窗口大小。关闭宽屏窗口后，在 Eagle 里打星仍会记为决定。
- 右栏点「宽屏查看」时若插件窗口正在提交任务或有对话框打开，不会打断，只在主界面提示稍后再点。

## 验证

- 单元测试覆盖：本地服务的宽屏请求（等待、通知、重启后的处理、超时）、窗口监听不空转、页面切换地址、宽屏下不写右栏专用状态、
  从插件菜单回到主界面，以及右栏按钮的请求与失败提示。
- 面板夹具中检查了宽屏 1800、1200、700 像素与右栏 320 像素的布局，主窗口 360/420 像素顶栏，以及主界面与宽屏之间的往返。
- 全部测试与公开发布检查通过。
