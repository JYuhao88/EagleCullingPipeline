# 产品目标（v1.0）

做一个合格、完整、可用的 Eagle 照片筛选工具：摄影师在 Eagle 里选一批照片，工具把同一次拍摄的多个文件合并、把相似照片分组、在组内给出排序和理由，摄影师逐组快速确认，结果以标签写回 Eagle。macOS 与 Windows 都可用。

## 用户流程

1. **选择范围**：在 Eagle 中选中照片或文件夹，打开插件（先显示宽屏检查器），点「返回主界面」，再点“分析”。
2. **分析**（本地服务，可选 GPU）：
   - 拍摄单元：同名 JPG/HEIC 与 RAW（ARW/DNG/3FR 等）合并为一个拍摄单元，后续只按拍摄单元排序；无法唯一配对的单独处理并标明。
   - 代理图：优先 Eagle 缩略图/成片，其次 RAW 内嵌预览，不整张解码大 RAW。
   - 指标：清晰度、曝光、人脸与闭眼、整体质量/美学分（模型可选，未校准时明确标注）。
   - 相似分组：pHash 快速候选 + 语义向量（DINOv2）复核 + 拍摄时间/文件名相邻性。
   - 组内排序与理由：给出首选和每张的中文原因（模糊、闭眼、过曝等）。
   - 可中断、可续跑：结果按文件指纹缓存，重跑只算新增或变化的照片。
3. **审阅**（插件）：
   - 按相似组逐组显示，大图并排比较，组内缩略图条。
   - 键盘：`1` 保留、`2` 候选、`3` 淘汰、`Enter` 下一组、`←/→` 切换；“设为组内首选”一键完成。
   - 筛选：只看有问题的、闭眼、模糊、未审阅；显示进度。
4. **写回**：
   - 标签：`AI精选` / `AI候选` / `AI淘汰`，加问题标签（`AI闭眼`、`AI模糊`、`AI过曝`、`AI欠曝`）。配对的 RAW 跟随所属拍摄单元。
   - 不改人工星级、人工标签、文件夹、原片；写回幂等，可重复执行。
   - 可选：二次确认后把 `AI淘汰` 的项目移入 Eagle 回收站（默认关闭，永不自动删除）。
5. **报告**：导出 CSV/JSON（每张的分组、分数、理由、决定）。

## 质量门槛（“合格”的定义）

- macOS 上 `npm test` 全部通过（Windows 专属用例可以带原因跳过）。
- 在 Mac 测试库 `摄影素材清洗`（76 个文件，38 个拍摄单元）上端到端跑通：分析、审阅、写回、报告；原片 SHA-256 不变；配对 38/38 正确。
- 排序质量有数据支撑：在公开质量/美学数据集上报告所选打分模型的相关系数（SRCC/PLCC），并说明默认模型的选择理由与许可证。
- 分析不影响本机日常使用：默认并发受限，资源占用可配置。
