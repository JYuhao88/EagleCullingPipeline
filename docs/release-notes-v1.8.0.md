# v1.8.0 发布说明

「细节与调节」的局部图改为滚轮缩放，并能标出相机的对焦位置和画面里真正清晰的地方。只影响显示，
分析、评分、排序、规则、分组、依赖与 lockfile 均未改变。

## 缩放

- 滚轮或触控板双指以光标为中心连续缩放，拖动平移，双击在适应和 100%（原图一像素对一个屏幕像素）之间切换。
- 原来的「适应 / 2× / 4×」按钮去掉，右下角显示当前比例，点一下回到适应。
- 在适应状态下向下滚动仍然滚动右栏；放大后会自动换取更清晰的显示图。

## 对焦提示

- 「对焦框」画出相机记录的对焦位置，实线是合焦的区域，打开时默认放大到那里：
  - 索尼：对焦位置和对焦框大小；
  - 理光 GR（以及宾得格式）：对焦区域和合焦标记，人脸识别对焦时框在脸上；
  - 哈苏 3FR 不记录对焦点，会注明“这台相机没有记录对焦点”。
- 「合焦高亮」把当前看到的清晰边缘标红，所有相机都能用；它反映当前显示尺寸下的锐度，放大到 100% 附近判断最可靠。
- 对焦位置在打开局部图时按需读取原图的相机信息，不写入分析记录。

## 验证

- 在资源库的索尼、理光照片上把读出的对焦框画到照片上核对位置和旋转方向；哈苏 3FR 确认没有对焦点信息。
- 单元测试覆盖光标处不动的缩放、边缘夹紧、100% 比例、对焦框解析与旋转、合焦高亮和对焦点接口。
- 全部测试与公开发布检查通过。
