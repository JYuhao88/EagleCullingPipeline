# 同场景并排比较

## 操作

在“审阅”的相似组照片卡片点击“并排比较同场景”。左右各显示一次拍摄，可从选择框切换组内其他拍摄，也可“交换左右”。当前选中的拍摄放左侧；默认另一侧取不同拍摄，不把 JPG/RAW 或 HEIC/3FR 配对当两张重复照片。

“在 Eagle 中定位”用于检查原生预览；“设为组内首选”复用已有确认及持久审阅队列，把首选及确认配对设为精选，其余拍摄设为待复核。不是删除动作，不改星级或文件夹；具体保护、部分写入和失败恢复规则仍见 `priority-review.md`。演示模式、维护任务运行或审阅计划创建中停用写入按钮。

## 图片与资源边界

- 只显示当前 Eagle 提供的 `thumbnailURL`，不读取原片 URL、不启动模型、不解码 RAW、不写自定义缩略图或元数据。无缩略图时显示明确提示，不偷偷加载巨大的原片。
- 确认配对按完整成员 ID 集合合并，优先有预览的 JPG/HEIC；若其不可显示而 RAW 有缩略图，使用现有 RAW 缩略图。重名不确定组不合并。
- 两个显示区使用 `object-fit: contain`，不裁切构图。只有两个大图显示元素，不因为组中照片多就解码整组预览。
- 使用现有缩略图不等于原图锐度或 RAW 动态范围。小缩略图放大仍会模糊，不能宣称解决原生高清预览；历史写入的角标像素也可能仍在其中。
- 界面重新渲染时比较签名不变则保留图像节点，避免后台进度更新反复重建同一对图片。关闭后清除节点和引用；这不等于强制清空浏览器自己的图片缓存。
- 模态比较时列表 J/K、1/2/3 快捷键不穿透到背景。资源库变化时关闭旧比较，点击动作前再检查原资源库，避免操作旧视图。

## 验证（2026-10-09）

单元测试覆盖配对成员顺序不同仍合并、成片选择、未知重名保持独立、无成片缩略图时回退、左右不能选同一个拍摄、数据不变。Edge 渲染测试验证双栏位置不重叠、图片不裁切、交换左右、演示写入禁用、背景快捷键不穿透、异步关闭后图片节点清空；已有队列及成对写回测试继续通过。

首次新增关闭清理断言未等待浏览器异步 close 事件而失败，现明确等待事件完成，不跳过断言。完整测试达到 138 项，实际 Eagle 中的比较、首选保存和高清定位仍需生产升级后验收。不要把 Edge 模拟界面验收说成已经操作真实桌面。
