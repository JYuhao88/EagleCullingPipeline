# v1.2.4 发布说明

修复「关于 / 更新」与勾选框显示问题。排序、规则、评分模型、分组逻辑和依赖均未改变。

## 修复

- 点「检查更新」会立即向 GitHub 查询最新正式版，不再沿用最多 6 小时的检查缓存；两次手动查询至少间隔 1 分钟。空闲时的自动检查仍每 6 小时联网一次。
- 「关于 / 更新」显示上次检查时间；有新版本但暂时不能更新时，同时显示新版本号和原因。
- 修复所有勾选框被撑宽到 360 像素的问题（自动更新、写回时移入回收站、个性化设置等）。

## 验证

- 浏览器中实测：旧版本手动检查可立即发现新版本并显示更新说明；勾选框与文字对齐。
- 新增手动检查限频测试；完整回归 450 项通过，公开检查 0 命中。
