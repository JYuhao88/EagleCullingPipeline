# v1.2.8 发布说明

Windows 兼容性维护版本，只改测试和开发脚本。插件、分析服务、排序、规则、评分模型和分组逻辑均未改变，依赖与 lockfile 未变。

## Windows 实机验证（v1.2.7 功能）

- 结果缓存：冷算后重算全部命中，结果逐字段一致；移动缓存目录后仍然命中且一致。
- 缓存上限：非法上限被拒绝，合法上限生效；清理预览后重算结果一致，清空全部后占用归零。
- 空闲预处理：运行中不出现在状态和最近记录里；用户开始正式分析时立即让出并取消；完整预处理后，正式分析这些照片直接读取缓存。
- 自动更新：已安装的服务从旧版本自动更新到 v1.2.7 并重启成功。

## 修复

- 开发脚本 `scripts/profile-focus.mjs` 在 Windows 上动态导入临时模块失败（绝对路径不是合法的 ESM URL），改为通过 file URL 导入。
- 测试不再假设 macOS：普通性能模式在 Windows 上不使用 `nice`、仓库路径使用 Windows 绝对路径、规则审核指南比较前统一换行符、只在 macOS 上校验姿态缓存的 CPU 推理记录。
- 缓存、预处理相关测试在 Windows 上更稳定：等待后台分析真正开始后再继续；先关闭服务再删除临时目录，并在文件被短暂占用时重试，避免测试进程挂起。

## 已知情况

- 研究脚本测试依赖 `python3` 命令；Windows 上可用 `EAGLE_PYTHON` 指定 Python。
- 部分 Windows 机器的随机端口范围包含 fetch 禁用端口，使用随机端口的服务测试有极小概率报 `bad port`，重跑即可，不影响插件（服务使用固定端口）。
