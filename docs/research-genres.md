# 其他题材的选片评估与参考来源（2026-10-10）

目标是帮摄影爱好者和职业摄影师减少看片量，同时保留技术不完美但有价值的作品。本文接续 [下一代方案](next-gen-plan.md)、[人像研究](research-portrait-body.md) 和 [下一代契约](contracts.md#下一代契约2026-10-10见-next-gen-planmd)。**这是评估设计和规则种子，不表示新增测量、序列保护或风格豁免已实现。** 本任务不转写、不截帧，也不下载新检索到的 B 站视频。

日常流程只用本地测量和小模型，目标硬件 RTX 4070 Ti Super（16GB）。Codex / 可配置多模态服务 只在少量离线抽样上补充规则结论、组内比较，不部署大模型，也不把在线老师接入每次选片。教师输入遵循现有方案的缩略图和必要局部，私人照片的发送范围另按已有隐私约定处理。

## 1. 共用判断顺序与落地边界

1. 先完成 RAW/JPEG 配对，识别拍摄用途和需要保留的序列，再做相似分组。
2. 先确定需看清什么、交付尺寸和风格意图，再判断失焦、裁切或噪点是否构成硬伤。无法恢复且破坏必要信息，才提出技术拒绝。
3. 审美问题是比较理由，不是自动废片：主体、关系、层次、瞬间、光线各有不同贡献，不能强行加成一个普适美学分。
4. 保留多张不同信息的候选；合成源帧与叙事序列以整组保留优先于单帧 gate。没有足够证据时只提示并交人工确认。

规则库是 [`landscape.json`](../src/rules/landscape.json) 和 [`street.json`](../src/rules/street.json)，各 15 条。`check.by=measure` 表示可测量的候选检查，`teacher` 表示少量离线教师或以后学生预测，`measure+teacher` 表示数值与意图判断共同需要；**不是实现完成标志**。`gate` 只在适用性、置信度和例外检查后建议拒绝，仍由人确认；`penalty` 用于组内比较；`hint` 仅解释。种子暂用 `todo:book`，待专家抽取和用户审核后替换为真实课程集号/视频号与时间点；本任务未观看课程，不能补造出处或时间戳。

新信号应按 `UnitResult.signals` 的契约新增：缺失不写，坐标为已旋转代理图的归一化坐标；角度用度，原图裁切用 `source.width/height` 换算。本文的信号名是建议名，尚未成为可依赖的 API。规则结论使用 `pass / warn / violate / na`；无法评估不等于通过，缺失 EXIF、无可靠地平线、脸太小等都要保留“不知道”。相机元数据不要与学生猜测混在一起，记录来源、置信度、原生分辨率和解码类型。

优先做无学习测量：ExifTool 元数据、OpenCV 直线/局部梯度/匹配、原图区域直方图、噪声估计。再按需加现有人脸检测和 DINOv2-small 特征；RTMW 关键点接入仍需后续探针确认。显著性可先用 OpenCV spectral residual；单目相对深度可评估 Depth Anything V2 Small（官方 small 权重 Apache-2.0；其他尺寸不沿用此许可），只用于相对层次，不能当米制距离。新检测器/权重上线前逐项核对权重许可、测时和峰值显存，不默认所有 YOLO 权重都可自由商用。模型串行按需加载，原生细节先选少量 ROI，避免将高分辨率整图送入多模型。

## 2. 风光

### 2.1 真正淘汰的原因

技术硬伤：需要呈现的焦平面失焦；相机抖动让静止内容不可用；关键云层/地面曝光不可恢复；交付尺寸下噪声或降噪涂抹毁掉必要细节。轻微地平线倾斜、灰尘、可修复色偏通常是修复成本，不是淘汰依据。天空白并不等于 RAW 无法恢复，HDR 暗帧也不能单帧淘汰。

审美原因：画面没有明确观看路径或空间关系，前景抢戏，边缘意外干扰，光线与地形/主题没有形成作用，重复机位未增加内容。不能用“没前景”“地平线没在三分线”“没有黄金光”作为普适扣分；极简、类型学、雾景可以故意弱化这些因素。

### 2.2 候选信号和实现

| 信号 | 实现与证据 | 判断限制/规则 |
|---|---|---|
| 地平线倾角与高度、可信度 | 天空/地面分区 + LSD/Hough 线段，海平线与建筑水平线投票；报告角度和可校正裁切损失 | 山脊不是水平线；透视和镜头畸变先排除。阈值需按样例校准，不直接固定 1° 为拒绝；L-HORIZON-* |
| 天空高光、主体高光/暗部、动态范围 | 按天空/主体 ROI 分 RGB 通道测裁切比例；RAW 可用解码后线性值/黑白位核验，记录格式、白平衡和曝光处理；包围帧联合检查 | 嵌入 JPEG/色调映射图不能证明 RAW 不可恢复；太阳和反射允许裁切，直方图跨度不能代表传感器动态范围；L-EXPOSURE-DETAIL、L-SHADOW-RECOVERY |
| 全画面清晰度、焦平面 | 原生尺度分块梯度/频谱，前中后景 ROI 单独比；EXIF AF 点、SubjectDistance/MakerNotes 对焦距离作辅助；同镜头/光圈/景深组内比较 | 无纹理天空和雾不是失焦；小光圈衍射与景深有取舍，堆栈成员只负责自身焦平面；L-FOCUS-REQUIRED |
| 三脚架抖动 vs 长曝光 | 静止物边缘重影方向一致性 + 局部运动分布；邻帧配准后看固定山体/建筑与流水、云；EXIF 快门和稳定器信息辅助 | EXIF通常不能证明上了三脚架；慢快门并非抖动证据，需原图静止 ROI；L-BLUR-CAMERA |
| 噪声/涂抹 | 平坦区小波残差或局部方差，避开星点、纹理；结合 ISO、100% 细节和交付尺寸，检查提亮后的暗部 | JPEG锐化、压缩会改变噪声；不能拿不同输出尺度做直接比较；L-NOISE-DETAIL |
| 传感器灰尘 | 小光圈平坦天空的暗斑；同相机跨帧、传感器坐标稳定性验证，排除移动鸟/云，标修复成本 | 对旋转、裁切、镜头校正图需逆变换坐标；单帧只报候选；L-SENSOR-DUST |
| 前景、引导线、观看入口 | 显著性 + 线段 + 相对深度提取前景面积、路径和层间重叠；少量教师解释关系 | 显著性不是“重要性”，深度模型在反射、天空、雾上不可靠；L-FOREGROUND-ROLE、L-LEADING-LINES |
| 光线时段与色温 | DateTimeOriginal + OffsetTimeOriginal/时区 + GPS 可估太阳高度；RAW AsShotNeutral/相机白平衡及估计色温仅辅助描述 | 无时区/GPS 不计算可靠太阳时；色温会被后期改写，黄金时段不是分数；L-LIGHT-INTENT |
| 光晕、色带、边缘干扰 | 局部边缘残差和高亮显著性筛候选，教师结合全图和局部确认 | 避免把自然逆光轮廓当 HDR 光晕；L-NATURAL-COLOR、L-EDGE-DISTRACTION |

## 3. 街拍/纪实

### 3.1 真正淘汰的原因

技术硬伤限定为必要事件信息失去可读性：非故意失焦/抖动，曝光毁掉关键动作或主体；是否必须清晰与具体风格有关。闭眼、脸小、人物裁切、颗粒、背景遮挡，都不能直接套用摆拍人像 gate。

审美比较看这一帧中发生了什么：人物与门窗/标线/影子的对应，手势与步态，视线和人物间关系，前中后景能否辨读，反射和遮挡是否带来悬念，画面边缘是否偶然干扰。所谓决定性瞬间既可能是动作峰值，也可能是短暂的关系成立；静态街头与反决定性瞬间风格不必追求动作高潮。教师不得凭表情臆断身份、心理或冲突。

### 3.2 候选信号和实现

| 信号 | 实现与证据 | 判断限制/规则 |
|---|---|---|
| 人物与几何关系 | 人框/RTMW 关键点 + LSD 线段，计算中心、脚点与门窗/标线的相对位置和边界距离 | 数值只能说明关系存在，不能证明巧合有意义；S-PERSON-GEOMETRY |
| 层次与分离 | 人框重叠、关键点可见性、显著性区域、相对深度；比较邻帧的轮廓粘连和层间空隙 | 反射与玻璃会误导深度；不规定必须三层；S-LAYERS-SEPARATION |
| 决定性瞬间 | 连拍按时间展示 contact sheet；关键点轨迹、步态、手势、视线、移动物体位置提供变化证据 | 不用单张技术分替代事件判断；少量教师做两两比较并交换左右；S-MOMENT-ACTION |
| 遮挡、背景穿头、边缘半截 | 人框/分割/关键点可见性 + 高亮/线段交叠，筛候选后解释 | 遮挡可能是主题，穿头可能是幽默呼应；S-OCCLUSION-INTENT、S-BACKGROUND-MERGER、S-EDGE-CONTENT |
| 意图失焦、运动与颗粒 | 原图主体/静止背景 ROI、快门/ISO、局部频谱和运动方向，结合风格标签 | 脸和眼不一定是主内容；S-FOCUS-INTENT、S-MOTION-INTENT、S-NOISE-STYLE |
| 叙事覆盖与独特信息 | 同组接触表 + 动作/人物/场景变化，记录每帧新增的信息；叙事序列人工标记 | 不以 embedding 相似度直接丢掉独特事件；S-UNIQUE-COVERAGE、S-NARRATIVE-EVIDENCE |

## 4. 活动/婚礼/多人

专业交付比单张美学更强调覆盖完整：戒指交换、亲吻、致辞、拥抱、合影、重要宾客等独特事件，即使技术欠佳也可能必须保留。先由摄影师标关键人物和事件，再比较同事件连拍，允许一组多张；不能让普通宾客的一次闭眼压过唯一关键瞬间。

| 原因 | 信号与实现 | 处理 |
|---|---|---|
| 正式合影任一需交付人物闭眼/半闭眼 | 逐脸 `eyesAssessed`/闭眼分数、原生脸裁切，脸框跨帧匹配；同组检查所有人，并显示问题人框 | 正式合影高置信闭眼可作为 gate 候选；小脸/侧脸/眼镜反光不可评估则待审，不算睁眼；情绪闭眼和纪实瞬间豁免 |
| 必须入画的人被遮挡、漏拍或裁切 | 逐人检测 + RTMW 可见性，用户指定人员名单/关键角色与人数，检查脸和身体轮廓 | 人检测数不等于人数真值；拥抱和拥挤仪式需意图判断。身份匹配本地且人工核对，不默认额外上传人脸 |
| 多排人物焦平面不够 | 按行/人原生眼部清晰度、AF 点、焦距光圈；统计最差必要人及可信人数 | 无法评估的脸保留未知；不能以平均人脸质量掩盖最后一排失焦 |
| 主体曝光不均、闪光失败 | 逐脸高光/暗部、肤色通道裁切、闪光 EXIF 和邻帧差异 | 舞台灯和彩色灯不强制中性肤色；RAW可恢复先核验 |
| 表情/动作失误 | 同事件时间序列，逐脸表情与全图互动，少量教师比较 | 不强制所有人笑或看镜头；说话帧要看是否仍表达事件 |
| 重复美图却缺事件 | 用户事件/关键人物覆盖表，帧时间与证据；独特事件召回 | 先保覆盖后收窄重复候选；姓名/事件不可由教师凭空生成 |

本轮不新建活动规则文件；后续以人像规则为组件，增加“逐人必要性”“正式合影 vs 纪实事件”“事件覆盖”适用条件，避免直接复用人像全局闭眼/坏切 gate。

## 5. 静物/建筑（简略）

静物硬伤是关键材质/文字/商品部分失焦、不可恢复反光裁切、色彩还原不满足交付要求；候选信号是主体/文字 ROI、焦点堆栈、反光掩码、色卡和均匀区噪声。产品交付可要求色卡真值，艺术静物不强制中性色。灰尘、布景杂物通常记录修复成本。

建筑看可信垂直线的汇聚、滚转、畸变，主体是否被无关边缘裁切，以及功能/空间是否清楚；LSD + 消失点估计、相机姿态/焦距、对称性和相对深度可辅助。仰拍透视、倾斜和类型学的平淡光线都可能有意，不能机械“拉直”；全景和移轴多帧先保护源序列。

## 6. 序列识别：先保护整组，再选单帧

这是后续实现的前置要求，当前相似分组没有本节保护能力。RAW/JPEG 配对仍为 CaptureUnit；合成序列应在其上新增独立关系记录（提案，尚非已实现契约）：`sequenceId/type/unitIds/orderedUnitIds/confidence/evidence/preserveAll/status`。不要把一个全景压成一个 CaptureUnit；不要覆盖人工分组/决定。

### 6.1 EXIF与视觉联合检测

先按相机机身（序列号可用时优先）、拍摄时间含亚秒、文件序号建立有间断的候选窗口，考虑文件时间不等于拍摄时间。保留 `ExposureTime/FNumber/ISO/ExposureBiasValue/FocalLength/SubjectDistance/DateTimeOriginal/SubSecTimeOriginal/OffsetTimeOriginal` 和可用 MakerNotes（驱动/包围模式、FocusPosition、AF点、相机姿态）。字段来源和精度都记录，不能把缺失值当 0。

| 类型 | EXIF候选证据 | 视觉核验与保留方式 |
|---|---|---|
| 包围曝光 HDR | 短时间同焦距/构图；曝光补偿常见 -/0/+ 或 0/-/+ 周期；结合实际曝光量 `log2(t × ISO / N²)` 检查等步进 EV 与循环重置 | 配准静止区域基本相同，亮度有系统变化。ExposureBias可不变，手动包围同样可检出；auto-ISO/光线变化会误报。每一循环全部保留，包括过暗/过亮帧；多循环不可混为一张组内赢家 |
| 全景接片 | 焦距通常稳定、短间隔、曝光常锁定，相机姿态或特殊软件标签可辅助 | **普通 EXIF 通常不记录云台平移/转角**，不能编造该信号；用 SIFT/ORB + RANSAC 单应变换检查连续横向/纵向位移、邻帧重叠与覆盖扩展，支持多排/蛇形顺序。固定云台转动与普通移动需区分，视差大时转人工；边缘首尾帧必须保留 |
| 焦点堆栈 | 构图/焦距/曝光大致不变，对焦距离或 MakerNotes FocusPosition 按顺序变化，部分相机有 FocusBracket 标签 | 配准后比较局部最清晰区域在前后景间迁移，允许 focus breathing；SubjectDistance常缺失/量化严重/为无穷，缺失不能否定堆栈。每个焦平面源帧都保留，不能要求单帧全画面清晰 |
| 延时 | 至少一串近似稳定间隔，观察中位间隔与 MAD、长间断和模式变化；有区间拍摄标签优先 | 构图静止或沿轨迹渐变，云、人、光线变化连续；星轨/日转夜允许快门和曝光变化。不用固定“间隔1秒”覆盖所有任务；漏帧记 gap，重复源帧仍由摄影师确认，不按相似去重 |

光圈、ISO和快门的 EV 只是元数据相对量，不是 RAW 像素亮度的精确模型，ND 滤镜、闪光、镜头透射和灯光闪烁都可能干扰。焦距变化通常提示变焦/重构图边界，**不是焦点堆栈的充分证据**；多焦距拼接/变焦延时可存在，低置信保护。对焦距离变化也可能来自自动追焦，须结合静止构图和焦平面迁移。

### 6.2 歧义与冲突

- HDR 全景、HDR 延时可嵌套：外层序列的每个位置/时间点包含包围子组。支持多标签/层级，不强制唯一类型。
- 秒级时间、缺失 EXIF、处理过的 JPEG、漏帧、多个相机并行、重复文件名、时钟误差都纳入负例。元数据不足但视觉强相关时标 `suspected` 并保护，而非当普通连拍。
- 高置信合成序列不提供成员级相似拒绝建议，先展示用途与完整性；损坏成员也保留问题标记并提示缺口。人工明确解锁后才允许收窄，记录操作证据。
- 叙事连拍不像合成序列那样有固定 EXIF特征，需要摄影师声明意图；街头/活动的普通连拍可以比较，但不得预设“每组恰好一张”。
- 参数以自有会话的真实序列校准：不先写死曝光步长、时间间隔、焦距误差或重叠率。高低置信分别报告误保护与漏保护，疑似多保护的成本通常小于丢源帧。

## 7. 可故意打破的规则与风格意图

| 风格/意图 | 常破的规则 | 标签与评估方式 |
|---|---|---|
| 新地形摄影/类型学风光与建筑 | 戏剧光、醒目前景、传统视觉中心、黄金时段 | `intent:typology`、`intent:flat-light`；评价空间/环境关系与系列一致性，平淡不自动低分 |
| Saul Leiter 式观看 | 主体完整可见、眼部清晰、背景分离 | `intent:occlusion`、`intent:reflection`、`intent:selective-focus`；检查遮挡与色彩/观看路径是否成立 |
| 森山大道式粗粝街头 | 无颗粒、全面清晰、平直稳定、柔和调子 | `intent:grain`、`intent:high-contrast`、`intent:motion`；看事件、张力与系列，不因高ISO扣分 |
| 长曝光、ICM、剪影、极简 | 冻结动作、完整细节、前中后景齐全、平均曝光 | `intent:long-exposure`、`intent:icm`、`intent:silhouette`、`intent:minimal`；检查是否符合本张意图 |

这些名字是风格参照，**不是声称上述摄影师逐条提出了本库规则**。例外以摄影师显式选择为最可靠来源；模型只能建议标签并提供证据，不自动替用户声明意图。标签豁免指定规则/单张/序列，记录来源与撤回，不全局免除所有技术检查。意图标签也不是“拍得成功”的证明，仍要在同组和交付语境比较。

后续课程抽取只保留提炼规则、课程名、集号和时间点，不复制大段原文。大师作品图像不进入仓库或公开训练集。风格例外须配摄影师自有正反例，优先用真实保留但破规则的照片校准。

## 8. 真值、公开数据与测试衔接

### 8.1 自有真值优先

按照 [test-plan.md](test-plan.md) 收集完整会话和摄影师最终选择：风光、无摆拍街头、活动/婚礼/多人各至少一次，与既有类别共同达到至少 6 会话、2000 张目标。细标注只补有价值的歧义：硬伤及必要ROI、修复成本、风格意图/豁免、同组并列、关键人物/事件、序列类型/成员顺序/完整性。照片在本任务不上传给教师；先做本地测量，后续试点按预算抽样20–50张。

序列真值必须由实际拍摄用途或摄影师核对：至少覆盖 HDR、单排/多排全景、焦点堆栈、固定/移动延时，以及普通连拍/自动追焦/自动曝光负例。跨相机、跨软件导出、RAW/JPEG 与缺失 EXIF 各有测试样例。专家单张点评及课程大师作品不能直接当同组选片真值。

### 8.2 公开数据集候选与许可边界

本任务只提出候选，不宣称已下载或已获商业许可。**“公开可下载”不等于“图片可再分发或用于商用训练”**；代码许可与图像/标注/模型权重分开核查，逐项记官方来源、版本、条款、原图版权和允许用途。未确认的素材不进入生产学生训练，不把公开图片拷进仓库。

### 8.3 T0/T1及新增诊断

- T0：`node --test test/rules.test.js` 校验种子契约；`npm test` 校验不新增失败。规则 JSON 通过不代表对应视觉功能已通过验收。
- T1：继续报告精选误拒率≤2%、30%预算召回≥80%、留出会话AUC≥0.70、找全精选的浏览量比时间顺序减少40%以上；随机、时间顺序、旧排序和新方案同表，给95%置信区间，按题材与意图标签拆分。
- 留一会话评估：调参/学生训练只在其余会话；整段视频/同专家系列按来源留出，避免教师评估看到相邻被点评图。
- 单项检测另报 precision/recall、适用覆盖率和不可评估率，重点看“有意模糊被误拒”“天空JPEG裁切但RAW可恢复”“合影小脸被当睁眼”。技术ROI与人工核对，绝不把模型输出自己当真值。
- 序列验收独立于单张排名：报告序列成员召回、误拆分/合并、类型识别和整组保护率；验收用例中已确认合成序列**零成员建议拒绝、零成员遗漏**，样本量和置信区间同时报告。新增预算策略应整组纳入，并单列预算超支；当前 `eval-picks` 的单元级预算不具备此机制，不能假称已支持。
- 活动另报关键事件/关键人物覆盖召回、正式合影“所有必要人均可用”的组级准确性；平均人脸分不能代替最差必要人物的检查。
- 消融：技术门槛 → 加规则 → 加意图豁免 → 学生/个人偏好；检查每步是否确实降低误拒，不重复奖励同一信息。现有eval脚本只直接列顶层数值signals，嵌套/序列信号的分项统计需后续实现，当前用独立研究报表。
