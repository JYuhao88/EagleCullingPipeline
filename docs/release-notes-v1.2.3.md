# v1.2.3 发布说明

系统性梳理插件前端，重做审阅页布局与分析进度显示。排序、规则、评分模型、分组逻辑和依赖均未改变。

## 审阅页

- 审阅页改为固定的应用布局：顶部标题栏、左侧组列表、中间照片区、底部快捷键栏。组列表与照片区各自滚动，整页不再上下滚动。
- 照片优先的卡片：按窗口大小计算列数和照片高度，一组照片尽量在一屏内并排显示；评分与理由收进可展开的「评分与理由」。
- 统一用语为「精选 / 候选 / 淘汰」；按钮上标出 1 / 2 / 3 快捷键，卡片右上角显示已做的决定。
- 「设为本组首选并完成（S）」放到每组顶部，并显示「本组已确认 x/y」或「本组已完成」。
- 批量接受、导出报告、写回 Eagle 收进顶部的「完成与导出」抽屉；操作结果在右下角提示，点击即可关闭。
- 写回预览生成期间显示进度提示，并防止重复点击；对话框打开时快捷键不会误改决定。
- 只有单张组的结果会自动切换到「全部」筛选，不再打开空白审阅页。
- 看图器：缩放比例按「适应窗口」的倍数显示；读取原图时显示加载状态；只有一张照片时隐藏左右切换箭头。
- 窄窗口和矮窗口下自动收窄侧栏、降低照片最小高度。

## 开始页与分析进度

- 开始页新增「继续审阅」，直接打开最近一次完成的分析；最近分析列表按时间排序并补全缺失的日期。
- 更新提示只在开始页显示，不再占用审阅页空间。
- 分析进度显示总体百分比、已用时间和根据实测速度估算的剩余时间，并细分为扫描、画质、特征、人脸、姿态、对焦、分组、排序各步骤。
- 人脸与姿态分析逐张更新进度；扫描阶段明确显示「读取资源库拍摄时间」。
- exiftool 常驻复用，人脸/姿态模型进程在一次分析内复用，减少重复启动开销；所有子进程仍以低优先级运行。

## 验证

- 在 1440×900 与 960×600 视口下逐项验证：开始页、打开 582 张的历史结果、新建分析与取消、审阅布局、快捷键、决定与撤销、完成与导出、写回预览、全窗口看图器。
- 新增审阅抽屉、写回预览、运行列表排序、模型进程逐张进度等测试；完整回归 450 项通过，公开检查 0 命中。
