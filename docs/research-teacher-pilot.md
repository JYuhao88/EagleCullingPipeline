## 方法与边界

`scripts/teacher-label.mjs` 是独立 CLI，只有显式 `--enable` 才允许远程请求。
正式 pipeline、排序、规则、信号和 Eagle 写接口均没有接入。
模型地址、凭据、总预算从环境变量读取；单价只读被忽略的 `config/local.json`。
本地配置形状为 `aihub.pricing[model].input/output`（USD／百万 token）、`aihub.usdToCny`。
批准的历史 run 结果位置只保存在本地 `aihub.authorizedRunResults`，公开脚本不保存其真实标识或照片路径。
公开文件不保存价格表、接口真实值或真实照片。

发送前将批准的缓存图像旋转归一、长边缩到最多 768 像素，再解码到裸像素，重新编码 JPEG。
新 JPEG 检查 EXIF、XMP、IPTC、ICC 均不存在，不发送原片、路径、人名、拍摄信息或系统排名。
请求只含匿名编号、通用任务说明和缩略图；返回完整无并列排序、每张 keep/reject、问题标签及最多 40 字理由。
支持结构化输出的通道使用非 strict JSON schema，同时进行本地字段、排列、决定、长度与路径内容校验。
通道明确不支持 `response_format` 时，可在本地 `aihub.responseFormat[model]` 设置为 `false`，
仅该模型改为提示词内 schema；本地校验和计费规则不变，仍按实际合法率报告可靠性。

所有模型串行；Sharp 并发 1、缓存 32 MiB，Node heap 上限 2048 MiB，并在取图／调用边界检查 RSS 3 GiB 软上限。
输出 token 上限通常为 6000，超过 40 张的组为 12000，包含通道计费的思考 token；
实际成本使用 usage，不用图片经验 token 数代替。
每次调用前持久化保守预算预留，按返回的输入／输出 usage 和调用时本地单价结算。
账本包含成功和非法 JSON 的费用。累计实付加未确认预留加本次预估超过任一预算上限即拒绝。
命令行预算必须显式设置；原试点上限 30 元，批准扩展后本轮累计硬上限 100 元，
包含原试点及未确认预留，同时服从环境变量中的总预算。
HTTP 错误、网络中断或 usage 缺失会保留预留，不能自动假定免费。
只有明确的 HTTP 429 拒绝和已结算的非法 JSON 可以重试，整个请求最多三次（两次重试），包括跨进程重跑。
429 记录为拒绝事件，保留原预留，默认按 30／60 秒退避；其它 HTTP 错误及网络状态不明时停止，需核对服务账单。
B 遇到一次 TPM 限流后成功退避续跑，本地 `aihub.minIntervalMs` 设为 10000，后续请求至少间隔 10 秒。
平均延迟统计收到 usage 的 API 调用时长，包含这些调用的重试，不包含串行节流、退避和图片编码时间。
已成功的结果从账本恢复，无再次请求或再次记账；未确认的相同请求拒绝重发。
锁阻止不同进程同时支出；异常终止留下的锁必须先审计原进程与账本。
账本及结果在 `data/cache/teacher/`，不入库。

A 从固定 T-syn 清单按退化类型分层轮转抽取 40 对，13 类每类至少 3 对，其中一类 4 对。
层内以固定 SHA-256 顺序选取，样本在四个模型间完全一致；原图位置交替，20 对各在第一／第二位。
SHA-256 核对实际输入字节，模型看不到退化名或已知优胜者。
准确率按原图首选计算，失败标签计为不正确；逐类报告样本数和正确数。这个真值是受控退化先验，不能当审美真值。
平均成本和延迟以每个尝试的图片对为单位，包含已收到 usage 的重试；JSON 合法率以这些调用为分母。
单独统计原始严格 JSON 合法率和本地规范化后的标签合法率；只移除完整代码围栏，不修造缺失字段或排序。
每类样本很少，重复源图和合成类别限制泛化，不据此给出全库效果保证。

B 只读批准的 291 单元历史 run，从其 42 个多图组按固定哈希顺序选 20 组。
只复用已有 preview 和 ranking，不重新分析。输入顺序独立于系统排名，同组所有图均发送。
A 选准确率最高的模型（同分选费用更低者），再选落后不超过 5 个百分点的最低成本模型，去重后最多两个。
这个规则预先固定，仍属于试点内选择，需要独立数据复验。
B 无标准答案，仅报告首选一致率、完整严格排序的 Kendall tau-a（各组等权平均），以及分歧清单。
本地分歧联系表包含同组所有图及双方名次，HTML 另列组 ID、首选和老师理由，供人工核对。

## 风险与建议

老师偏好不等于用户偏好；技术退化真值、模型意见和摄影师选择是不同证据。
缩图无法可靠评判原生细节，可能漏掉眼部失焦、噪点和小幅表情变化。
模型强制给出唯一排序可能掩盖并列、风格偏好和整组不满意；keep/reject 仅是老师建议。
不得将这些输出直接覆盖正式排序或人工决定，只可考虑冷启动先验或分歧提示。
扩大前需摄影师复核分歧、独立真实组留出验证、按题材检查偏差，并重新核对本地价格和预算。
500 元覆盖量只能按本轮实测组成本外推，不包含人工审核成本、未来涨价或未知请求费用。
