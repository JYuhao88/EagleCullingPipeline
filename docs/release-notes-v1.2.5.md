# v1.2.5 发布说明

缩短重复扫描、姿态模型加载和看大图放大的等待。排序、规则、评分模型、分组逻辑和依赖均未改变。

## 改进

- 拍摄时间缓存：按文件路径、大小和修改时间缓存 EXIF 拍摄时间与相机信息。582 张照片的重复扫描从约 45 秒降到 1 秒以内；照片被修改后自动重读。会话划分和分组结果与不缓存时逐字段一致。
- 姿态模型：Mac 默认改用 CPU。实测 CoreML 首次就绪 11.5 秒、内存 1.8 GiB，且最终回退到 CPU；直接用 CPU 时就绪 1.3 秒，关键点结果与之前完全一致。可用 `EAGLE_POSE_PROVIDER` 指定，用 `EAGLE_POSE_WORKERS`（1–2）调整进程数。Windows 行为不变。
- 看大图：打开大图时，在后台为当前和相邻照片生成长边 6144 的本机高清缓存。在 Retina 屏上第一次放大，1 亿像素照片从约 3.7 秒降到约 0.4 秒；接近 1:1 时仍读取原图。缓存默认上限 2 GiB，按最近使用淘汰；分析进行时暂停预取。

## 注意

- Mac 升级后第一次分析会重新计算一次姿态（缓存键随默认 provider 改变），之后照常复用。
- 高清缓存只用于显示，不参与评分。

## 验证

- 真实资源库：重复扫描冷/热耗时与分组一致性实测；浏览器中实测放大时走高清缓存，接近 1:1 时切回原图。
- 合成基准三项指标 delta=0；完整回归 470 项通过，公开检查 0 命中。
