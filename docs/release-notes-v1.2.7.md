# v1.2.7 发布说明

缓存更可靠、可控，并可在夜间空闲时提前分析新照片。排序、规则、评分模型和分组逻辑均未改变，依赖与 lockfile 未变。

## 缓存

- 冷算与缓存结果完全一致：此前命中缓存时，人脸曝光可能用到姿态模型补出的人脸框，个别照片曝光分会有不超过 0.03 的差异。现在缓存命中时只恢复检测器的人脸，38 个真实单元冷算与缓存重算逐字段一致。
- 移动缓存目录后仍然命中：结果指纹不再包含预览图的绝对路径。旧版本留下的缓存会在首次读取时自动迁移，升级后不需要重新分析。
- 缓存容量上限（默认 5 GB）：设置 › 缓存与预处理中可查看占用、选择上限（2/5/10/20/50 GB）。超过上限时，在分析结束后或服务启动一分钟后自动删除最久未用的缓存，删到上限的 90%：先删预览和中间图，其次特征和对焦，最后才删分析结果。最近 24 小时用过的缓存和正在分析的内容不删；拍摄信息索引和旧版共享结果只计入占用，不自动删除。
- 一键清理：「清理预览」只删预览和中间图；「清空全部」删除所有可再生缓存（需确认）。分析进行中不允许清理。删除缓存只会让下次分析变慢，不影响结果。

## 空闲预处理（默认关闭）

- 在设置中开启「空闲时预处理新照片」后，后台服务在设定时段（默认 01:00–07:00）内，且插件窗口关闭、电脑接通电源、空闲 10 分钟以上时，分析最近 30 天导入且尚未分析过的照片（单次最多 300 张）。之后正式分析这些照片时直接读取缓存。
- 打开插件窗口、电脑恢复使用、拔掉电源或离开时段时立即暂停；用户开始正式分析时，预处理自动让出。
- 预处理只读：不写标签、星级或文件夹，不出现在最近记录和完成通知中，只在设置里显示「上次预处理」时间和张数。始终使用普通性能模式。
- 无法确认电源状态时不运行。macOS 读取系统空闲时间；其他系统读不到空闲时间时只按时段判断。

## 验证

- 38 个真实单元：冷算 49.7 秒；把缓存目录搬到新位置后重算 0.57 秒，结果逐字段一致；在旧版缓存上原地重算 38/38 命中且一致。
- 在真实缓存上按上限淘汰预览后重算 4.8 秒，再淘汰到只剩部分分析结果后重算 28 秒（14 个单元重新计算），两次结果都与冷算逐字段一致。
- 完整回归通过，公开检查 0 命中。设置页在明暗主题下已截图核对。
