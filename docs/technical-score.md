# 技术粗排与未评估指标

## 修正原因

旧版将三分网格中最强局部纹理的方差推算成“主体分”和“构图分”，并各占总分 10%。这不是主体识别，也不是构图或审美质量模型；主体值很容易饱和到 100，误导留存排序。

新版不再用这两项推算总分。`metrics.subjectScore`、`metrics.compositionScore` 明确为 `null`，表示尚未评估，而不是 0 分、50 分或满分。审阅解释明确说明它们不参与分数，不能当作已实现的主体/审美评估。

## 当前分数是什么

仅保留预览的边缘变化量、亮暗截断比例，以及真正从分析原文件核验的分辨率代理项。仍沿用原相对权重 0.45/0.20/0.15，并按可用项权重之和归一化：分辨率核验时除以 0.80，代理预览未核验原分辨率时除以 0.65。未知原片分辨率不会作为低分辨率扣分依据。

这些指标仍是技术启发式，不能准确区分焦点是否在主体、背景纹理与主体清晰度、故意剪影/高调画面、摄影审美。闭眼仍由未校准的人脸阈值提供疑似信号；未检出不等于正常。没有因为移除伪主体分就宣称准确性达标。

灰度输入现在先转换为 sRGB 再计算亮度，避免将单通道图像按三通道读取而产生非有限值。没有改动输入照片颜色或原片，只转换分析缓冲。

## 版本与验证

评分版本更新为 `preview-v3-technical-only`，使旧版结果显示为历史/过期评分，不自动覆盖人工审阅标签、评分或文件夹，也不自动对全库重算。DINO 向量的输入、模型与预处理没有变，语义缓存不必因技术分数更新而无意义失效。
