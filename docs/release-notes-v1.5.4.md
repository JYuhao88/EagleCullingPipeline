# v1.5.4 发布说明

插件和检查器的颜色改为跟随 Eagle 实际显示的主题。只改界面颜色；排序、规则、评分权重、分组算法、依赖与 lockfile
均未改变。

## 主题识别

- 按 Eagle 自己的规则确定主题：Eagle 读不出主题设置时显示「灰色」，「自动」在系统深色时显示「灰色」、浅色时显示「浅色」。
  之前这两种情况都按「深色」显示，Windows 上主题设置以旧格式保存时尤其明显。
- Eagle 报告的主题无法识别时，右栏检查器改用 Eagle 随页面传来的实际主题。
- 在 Eagle 里切换主题后，插件和检查器立即跟着换色。

## 配色

- 六套配色（浅色、浅灰、灰色、深色、蓝色、紫色）取自 Eagle 自身的颜色：主界面和宽屏检查器用 Eagle 窗口底色，右栏检查器用
  Eagle 右栏底色，按钮、边框、次要文字和强调色也按 Eagle 的规则取值。
- 右栏检查器在新照片载入前先画的底色也改成同样的颜色，切换照片时不再闪出不同的底色。

## 验证

- 单元测试覆盖：主题名规范化（自动、无法识别时为灰色）、Eagle 报告 "undefined" 时改用页面传来的主题、有效主题优先于页面参数。
- 面板夹具中目视检查灰色、浅色右栏和主题无法识别时的宽屏页，底色与 Eagle 一致。
- 全部测试与公开发布检查通过。
