# 本地语义分析缓存：实现与验收记录

## 行为

新版服务默认在 `data/cache/semantic` 保存 DINOv2 成功结果；不写 Eagle 原片、缩略图、标签或元数据。每批相同预览内容只推理一次，返回结果仍使用各自项目 ID。

缓存键包含预览文件的 SHA-256、模型实际 SHA-256、模型清单、预处理配置、Python 推理代码和向量版本，以及 CPU/DirectML 后端。不依赖文件名或照片 ID，也不把相同场景当作相同内容。

每个分析池首次使用时校验本地模型校验和，包括只读取缓存的情况。驻留期间模型/配置文件的大小、修改时间或创建时间改变会拒绝结果，要求重启服务，避免将旧会话算出的向量记为新版本。升级服务后新的指纹使旧缓存自然失效。

读取检查向量版本、384 维有限数值和单位范数；损坏缓存重新推理，失败结果不缓存。推理后复查预览内容哈希，变化则不保存。缓存写入采用临时文件再重命名；写入失败保留有效推理结果，并计入诊断 `writeErrors`。取消任务不会当作分析失败。

诊断字段 `semantic.cache` 提供 `hits / misses / writes / invalid / writeErrors / inferenceItems`。`inferenceItems` 是实际送入模型的去重任务数，不等同于照片数。命中缓存不需要启动模型进程。
