# v1.2.6 发布说明

界面改成更像 Eagle 插件的形态，分析再提速约三分之一。排序、规则、评分模型和分组逻辑均未改变，依赖与 lockfile 未变。

## 界面

- 紧凑任务面板：插件窗口缩小为约 420×600，只显示当前选择范围、分析按钮、进度和「开始审阅」。最近记录只列 3 条，其余在「全部记录」。服务地址、仓库路径、启动命令、按运行 ID 打开等收进「设置 › 高级 / 诊断」；全速模式、个性化、关于与更新也在设置里。
- 跟随 Eagle 主题：配色和字号跟随 Eagle 的明暗主题（LIGHT、LIGHTGRAY、GRAY、DARK、BLUE、PURPLE），切换主题时实时更新。
- 全屏比较审阅：进入审阅时窗口放大，返回面板时恢复。默认比较视图按照片横竖自动排布（4 张横图为 2×2，竖图并排），另有单张（V）和网格（B）视图、底部胶片条、可收起的组列表。精选/淘汰显示为角标，分数和理由按 I 展开。原有快捷键全部保留。
- 检查器插件（新增，需另外导入 `src/inspector`）：在 Eagle 中选中一张照片时，右侧栏显示建议、组内名次、分数、对焦状态和淘汰原因。需要 Eagle 4.0 Beta 17 或更新版本。

## Eagle 集成

- 后台服务：插件随 Eagle 启动，本机分析服务未运行时自动拉起（可在设置中关闭），不会重复启动。分析完成或失败时弹出 Eagle 系统通知，同一次分析只通知一次。
- 实时写回（默认关闭）：在设置中开启后，审阅决定实时写成 Eagle 的 AI 标签，并可在完成页一键撤回。可选「精选写 5 星」，只在照片原本没有星级时写入，撤回时恢复。可选自动创建「AI精选」「AI待淘汰」智能文件夹（需要 Eagle 4.0 build22 或更新版本），同名时复用。

## 性能

- 姿态模型 CPU 线程默认 3；对焦分析每张原图只解码一次，眼部和人脸区域按 8 像素块对齐编码，结果逐像素不变。38 个真实单元冷算从 77 秒降到 51 秒，Node 内存峰值从 2.1 GiB 降到 1.5 GiB。
- 全速模式（默认关闭，设置中开启）：适合电脑空闲时整批分析，内存超过保护阈值时安全取消本次分析而不会崩溃。

## 注意

- 升级后需要重启一次 Eagle，后台服务和窗口尺寸才会生效。检查器需在 Eagle 中另外导入 `src/inspector` 目录，之后随仓库一起更新。
- CoreML、小模型和量化仍是默认关闭的实验开关。

## 验证

- 四次前台冷算（修改前、新默认、全速、合并后）分组、排序和逐字段结果一致；缓存命中重算 38 个单元 0.6 秒。
- 完整回归通过，公开检查 0 命中。明暗主题下的面板、审阅、检查器均已在浏览器预览中截图核对。
