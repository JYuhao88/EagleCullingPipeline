# v1.2.2 发布说明

重做审阅页的看图交互。排序、规则、评分模型和依赖均未改变。

## 改进

- 新的全窗口看图器：双击照片（或按 Z / 空格）打开，占满整个插件窗口。
  - 滚轮或触控板捏合以光标为中心缩放，放大后可拖动平移，平移不会超出照片边缘。
  - 双击在「适应窗口」与放大之间切换；`+` / `-` 缩放，`0` 复位；←/→ 切换同组照片；1/2/3 直接标记；Esc 关闭。
  - 放大超过预览图分辨率后，自动按可见区域加载原图像素，细节不再是放大的预览图。
- 审阅页铺满窗口：去掉 1280 像素的最大宽度，最大化后照片随窗口变大；开始页最大宽度放宽到 1200 像素。
- 移除「单击放大整组、照片跟随鼠标移动」的旧行为；单击只选中照片。

## 验证

- 1920×1080 视口下验证布局铺满、单击不变形、看图器缩放/平移/切换/复位。
- 新增看图器几何与原图区域裁剪测试；完整回归通过，公开检查 0 命中。
