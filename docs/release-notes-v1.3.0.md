# v1.3.0 发布说明

按摄影师的使用习惯重新设计挑片流程：首页以“任务”为中心，挑片可以在 Eagle 原生界面完成，也可以在插件里用逐张、网格、AI 先挑、分轮四种方式专注挑片；RAW 与 HEIC/HEIF 的显示清晰度问题从根上修复。排序、规则、评分模型和分组算法未改变，依赖与 lockfile 未变。

## 首页与任务

- 首页按任务状态给出唯一的主按钮（继续挑片、继续分析、写回、分析新选中的照片），任务列表按“需要处理的”排序，两栏布局适配宽窗口。
- 重新打开时保留未完成的工作：可续跑的分析显示“继续分析”，不能续跑的给出“按原范围重做”或“重新选择”；补充分析或重新分析后，已挑过的照片按照片继承原决定，旧版本标为“被取代”。
- 窗口不再自动最大化或缩回，记住上次大小；需要时点“放大审阅”。

## 挑片方式

- **在 Eagle 中挑（默认）**：插件窗口是紧凑遥控器，显示进度和带数量的筛选（未决定、没把握、建议淘汰、有问题），1/2/3/0 记录决定，可自动下一张、跟随 Eagle 选中。右侧检查器可直接决定、看本组、跳到下一张未决定。
- **AI 建议标签（默认关闭）**：按任务开启后写入 Eagle 资源库标签（不改照片文件），决定变化时同步更新；关闭可精确恢复原标签，也可一键清除插件写入的全部 AI 标签。
- **在插件里专注挑片**：逐张大图 + 胶片条；网格批量（Shift 连选、⌘/Ctrl 点选）；AI 先挑（设定保留张数，只看保留线附近和有问题的照片，其余一键按 AI 结果确认）；分轮（去废片 → 组内比较 → 复核精选）。每个任务记住方式、筛选和位置。
- **查看调整**：曝光、对比度、高光、阴影、色温、色调、饱和度和自动曝光，在逐张、看原图和组内比较里一致显示；只影响显示，参数按任务保存在本机，不改原片、不导出、不参与评分。

## 清晰度与格式

- 新增按显示尺寸取图的显示档（1024–6144，不放大原图），大图、比较卡片和逐张视图都用它，放大时自动升档。
- RAW 显示优先用足够大的内嵌预览，不再把很小的内嵌缩略图拉伸显示；RAW 扩展名补全（CR3、CRW、NRW、PEF、SRW、SR2、ERF、IIQ、X3F 等），分析、配对、检查器统一使用同一份列表。
- HEIC/HEIF：macOS 用系统解码；Windows 通过微软商店的「HEIF 图像扩展」+「HEVC 视频扩展」（WIC）全分辨率解码。Windows 上 RAW 在其它方式失败时用「Raw 图像扩展」解码。
- 降级到 Eagle 缩略图的缓存不再永久保留：服务每次启动会重新尝试一次解码，查看器会标明“低清”。

注意：Windows 上的 HEIC 和部分 RAW 以前是用 Eagle 缩略图分析的，现在会用真实解码结果分析，这些照片的分析分数可能与旧版本不同；新识别的 RAW 格式会与同名 JPG 配成一个拍摄单元。

## 其它修复

- 大图查看器底栏的文件名、缩放比例和提示文字在所有主题下都看不见（颜色与背景相同），已修正；审阅页主按钮、进度、写回说明等同类问题一并修正。

## 验证

- macOS 完整回归通过，公开检查 0 命中；专注挑片与遥控器在 1440/1024/800/420/360 宽、明暗主题下用浏览器实测操作。
- Windows 实机（开发副本，资源库只读）：显示档对真实 HEIC 走 WIC 全分辨率解码、方向正确（首次约 3.5 秒，之后走缓存），分析代理图不再是缩略图；ARW 用全尺寸内嵌预览；DNG 不再读到 160×120 的内嵌缩略图而是真正解码（6020×4024）。Windows 全量回归除已知的 python3 缺失外全部通过。
