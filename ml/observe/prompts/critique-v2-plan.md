# critique-v2：提示词修改与前瞻参照方案

状态：**待冻结的 v2 预注册方案；本轮不执行 v2，没有 v2 验证结果。**
这是依据 v1 结果制定的下一轮设计，不是 v1 的预注册修订。v1 的提示词、参照规则、门槛和失败结论保持原样。
配套机器可读草案为 `critique-v2-preregistration-plan.json`；它不是可提交作业的正式预注册文件。

## 修改依据（事后描述，不作为验收）

MiniCPM 照片主问按 v1 三家参照得到以下编辑**合理性**；这不同于报告 `categories.edit:*` 的事实正确性。
分母只含三家一致合理或至少两家不合理的编辑，其余为争议。

| 编辑 | A 合理/判定；合理率；Wilson 95% 下限 | B 合理/判定；合理率；Wilson 95% 下限 | A / B 争议 |
|---|---|---|---|
| 裁剪/拉直 | 12/32；37.50%；22.93% | 12/30；40.00%；24.59% | 26/58；25/55 |
| 曝光 | 23/44；52.27%；37.94% | 22/42；52.38%；37.72% | 38/82；40/82 |
| 去除干扰 | 53/54；98.15%；90.23% | 72/78；92.31%；84.22% | 26/80；35/113 |

去除干扰适合作为 v2 的受限候选；各 action 的有效判定都不足 140，不能据此宣称该类别已通过验收。
A/B 涉及相同照片，不能相加充当独立样本。高合理性也不能替代干扰物、位置及理由的事实正确性。
照片陈述争议率 A 81.72%、B 74.68%，说明只看已判定语句的精确率不足以评价全部输出；v2 必须同时检查参照覆盖。

## 提示词的具体改动

保留单图、无元数据、长边不超过 768 的输入；不增加原片或高分辨率证据。A/B 仍只相差冻结的专科正类事实块。
仍以短中文输出，各观察、位置、证据与理由均不超过 12 字，summary 不超过 30 字。
保留 v1 的 action/category 枚举以便描述复跑，规则限制哪些情形允许发言；不通过删掉历史错误记录改善 v1 分数。

1. **裁剪/拉直默认留空。** 仅在完整可见的长直线明显倾斜，或边缘有明确可移除干扰且不会裁掉主体时提出。
   不以“三分法”“居中不好”“更紧凑”等偏好作客观问题；不能确认直线为应水平/垂直的真实参照时不建议拉直。
   不从 768 图估计精确角度、比例或画外空间。上述条件不足时不输出 `crop/straighten`。
2. **曝光不常规推荐。** 仅在指定区域存在清楚的大片黑/白、主体因此难辨时描述当前显示图的现象。
   不声称原片欠曝、过曝或高光可恢复，不推断 RAW 余量；不为夜景、逆光或高反差风格自动提亮。
   编辑只允许针对该证据区域的一项保守操作；未看见可改善的内容时，`exposure/highlights/shadows/local brightening` 留空。
3. **去除干扰保留为受限候选。** 必须说清可见物体、位置，以及它与主体重叠或靠近边缘等可核实关系。
   只建议移除局部、小范围、与主体分离的物体；不把“背景有人”直接等同于必须移除。
   物体身份不清、移除会破坏主体或需要猜测遮挡内容时不建议。高合理性候选仍须重新满足事实及编辑两道门槛。
4. **删除细节和风格推断。** 不输出毛孔、微小皮肤瑕疵、精确焦点、细微噪点或锐度判断；
   `retouch skin/blemish`、`sharpen/denoise` 在这一输入分辨率下保持空缺。
   `white balance/color/saturation` 不以个人偏好判断冷暖、肤色或滤镜；没有图内可核实依据时留空。
5. **问题和编辑强制带证据。** v2 Schema 中，每条 issue 增加唯一 `id` 和必填 `region/evidence`，每条 edit 增加必填 `region/evidence/issue_id`。
   `region` 指向画面位置，`evidence` 描述可见物体及现象；edit 的 `issue_id` 必须引用已列问题，位置和证据一致。
   例如仅作格式示意：问题“右下角路人遮挡”，位置“右下角”，证据“路人挡住衣摆”；编辑仍须满足上面的移除限制。
   “更美”“更通透”“突出主体”不能单独作为证据或理由。教师须核验问题、证据和位置，任一明确不符即判该原子陈述错误。
6. **明确弃权。** 没有证据时 strengths/issues/edits 使用空数组；不用 `none` 凑编辑数。
   `summary` 仅概括已列证据，不补充判断；`verdict` 只表示本次单图建议，不能触发真实删除、排序或决定。
   图像不足以支持整体建议时使用“看不清”；不把单项细节看不清扩写成整图不可用。

拟加入系统提示词的核心文字：

> 每条问题必须指明图中位置和一个可见证据。每条编辑只能修正一个已列问题，并引用其编号、位置和证据。
> 裁剪、拉直、曝光不是默认优化；看不见具体问题就不建议。不要把构图、明暗、冷暖偏好写成客观错误。
> 仅对位置明确且不伤主体的小范围干扰建议移除。无法确认物体、证据或改善收益时留空。
> 不判断缩略图无法支持的细节。不凑条数，不编参数；没有可靠建议就输出空数组。

最终提示词的完整 Schema、合法/非法示例、解析器及语句拆分器须在执行前实现并冻结；本文件不能直接替代 `critique-v1.md`。

## v2 前瞻参照与门槛

每条主问的原子陈述分别由 flash、GPT、Claude 三个独立家族判断，教师不知模型或 A/B 身份。
教师继续区分“可见事实正确性”与“编辑合理且能改善”；风格偏好、看不清和缺答不混为错误。
正式 v2 教师 Schema 应另记 `cannotJudgeReason`，枚举为
`subjective_preference/insufficient_visible_detail/ambiguous_statement/other`，方便核查审美分歧、分辨率限制和语句含糊；
v1 没有这个直接归因字段，不能把 v1 的“无法判断”全部归因为看不清。

拟在执行前冻结以下 v2 规则：三家有效票齐全且至少两家正确、无人错误才计正确；至少两家错误计错误；其余争议。
编辑合理性同样要求至少两家合理且无人不合理；至少两家不合理计错误，其余争议。
一张有效票标“无法判断”可与两张同向正票形成正确；任何反对票均阻止正向通过，避免单纯多数掩盖明确反证。
没有三家完整有效票的语句标为缺参照，不能当作弃权票或“无人判错”；两张错误票可另列已观察错误下界，不能补成完整参照。
此规则允许一位教师的审慎弃权，但不接受一位教师的明确反对；它改变了 v2 参照定义，不能用来修正 v1 验收。

质量门槛维持：陈述正确率 ≥90%、Wilson 95% 下限 ≥85%、判定数 ≥140；编辑合理率 ≥85%、Wilson 下限 ≥80%、判定数 ≥140。
每个模型、变体和确认性数据集分别检查；照片 A、照片 B、Open Images A 不合并补条数。
`none`、空编辑不进入实质编辑分母；n=0 的率和 Wilson 记 null，不能写成 0% 或 100%。
置信下限仍以语句为单位，注明同图语句相关；A/B 差异按照片配对统计，不能把语句当独立配对照片。

为避免仅靠容易判定的少量语句通过，v2 增加前瞻覆盖条件：

- 全冻结清单推理与回执必须完成；保留现有 `fullyFormattedAndJudged` 完整性要求，任何缺失/错误/格式无效都不能报告全量验收。
- 每份格式有效主问的全部陈述都送三家，三家有效回执覆盖必须 100%；缺失或解析失败不自动重买，不缩减清单分母。
- 每个验收单元的陈述与实质编辑参照解决率分别 ≥80%。解决率为 `(正确+错误)/全部输出语句`，分母含争议和缺参照。
- 分开报告优点、问题、编辑、结论的解决率；有输出的每种语句也须 ≥80%。这是参照可用性条件，不是对其内容正确的证明。verdict 若仍无法由单图核实而长期弃权，也将触发该条件失败；不能为了达标把它的票删去。
- 必须达到上述 n≥140；若模型大多弃权、有效编辑不足，即使精确率 100% 也记证据不足。报告每张照片的输出数、空编辑率及各 action 计数。
- 声称某个类别已通过时，该类别还须单独达到同类质量、下限、n≥140 与解决率≥80%；不能用整体成绩替代。

完整分母同时保存：计划照片数、成功返回数、Schema 有效主问数、所有输出语句数、三票完整数、正确/错误/争议/缺参照数。
精确率为 `正确/(正确+错误)`；争议率和缺参照率分别以全部输出语句为分母。
另报保守已证正确覆盖 `正确/全部输出语句`；它不是替代精确率的验收门槛。
照片幻觉率至少报告已观察有错照片/全部计划照片、/有效主问照片，以及已解决照片分母下的条件率；未决照片不当作无错。
2/3 多数、无人判错等额外规则若再报告，只能列敏感性分析，不据此更换主规则。

## 执行前冻结与防止事后优化

本方案使用了 v1 的结果，因此现有 291 张照片和 200 张 Open Images 都属于开发证据。
v2 可在它们上做标为“开发集复跑”的比较，不能把该复跑作为独立确认性验收。
另选有合法来源、未用于 v1/v2 调整的留出照片与 Open Images；来源、样本数和固定散列抽样种子须在任何 v2 输出或教师调用前确定。
目前尚未指定该留出清单，故正式预注册尚未冻结。不能预先声称存在独立留出结果。

开始 v2 前，需一次性冻结并保存 SHA-256：完整 prompt+Schema、教师 rubric、解析/拆分代码版本、
模型 revision/量化与运行参数、A/B 专科事实快照、开发及独立确认清单、主/复问种子、
上述参照规则/质量与覆盖门槛、各模型/变体/数据集比较、预算及异常处理。
固定样本数后，不按观察到的精度或条数继续补抽；不够 140 或覆盖不足即记失败/不足。任何后续改动另起版本和新留出。
开发和确认数据不得按教师投票选择；不能挑三家更同意的类别、模型或照片后再称预注册成功。
两次固定种子的主问/复问用途仍分别为验收/类别 Jaccard 稳定性，不能挑较好的一次。
v2 本轮没有推理、教师调用、预算支出、上线或 Windows/GGUF 验收。
